Uma Trainer KR R20 · 게임 화면 자동 분류 / 스킬 이름 위치 인식

목표: 게임을 실행하면 작은 도우미가 화면 종류를 알아보고, 훈련/스킬 추천을 화면 위에 표시하는 구조로 발전시키기.
이번 R20은 자동 장면 인식의 구현판이며 한국 서버 PC 화면에서는 아직 검증하지 않았습니다.

[Windows에서 확인하는 방법]
1. 개발 환경에서는 실행.bat 로 메인 프로그램 실행 (Python 필요).
2. 첫 화면 '게임 동반자 R20'에서 '창 찾기' → 게임 창 선택 → '감시 시작'.
3. 미리보기에서 훈련 화면의 변하지 않는 버튼/문구 영역을 서로 다른 2곳 선택하고
   'R20 · 장면 자동 판별'에서 장면 '훈련'으로 각각 등록합니다.
4. 스킬 / 시설 / 이벤트도 별도 장면에서 서로 다른 UI 특징 2곳씩 등록하면 자동 분류 후보가 됩니다.
5. 훈련 표시 좌표는 R19 '게임 위 표시 위치 지정'에서 각 버튼을 한 번씩 보정합니다.
   기존 R6의 현재 턴 검수 추천이 유효해야 추천 후보 표시가 나옵니다.
6. 스킬은 스킬 구매창에서 '스킬 목록 영역 지정' 버튼을 누른 뒤 좌상단과 우하단을 선택합니다.
   Tesseract 한국어 OCR로 현재 목록에서 실제 이름을 확인했을 때만 표시합니다.
   R12의 현재 코스·각질 추천 검수가 없으면 스킬에 추천 표시를 붙이지 않습니다.
7. '게임 위 표시 + 옆 정보창' 버튼을 누르면 클릭 통과 오버레이와 정보 패널이 열립니다.
8. 상세 연구 기능은 오른쪽 위 '연구·상세 설정 보기 / 숨기기'로 열고 닫을 수 있습니다.

[이번 버전에 없는 기능]
- 실행하자마자 아무 설정 없이 한국 서버 모든 화면 자동 인식 (실화면 캘리브레이션 필요)
- 완전 자동 육성 / 자동 행동 선택 / 여러 턴 자동 클릭
- 실제 게임에 대한 OCR 정확도 검증, 한국 서버 설치형 EXE 실행 검증
- 유튜브 영상을 통째로 분석한 ML 학습 데이터셋

[동작과 안전장치]
- 장면별 화면 특징 2개와 연속 2프레임이 모두 맞아야 장면을 확인합니다.
- 화면이 불명확하면 즉시 숨깁니다. 창 크기의 종횡비가 달라지면 재확인이 필요합니다.
- 스킬 목록의 OCR 위치는 현재 화면의 이미지와 계속 일치할 때만 표시합니다.
- 훈련 위치는 동일 비율로 게임창 크기가 변한 경우에도 재보정해서 표시합니다.
- R18의 1회 수동 등록 클릭 시험은 별도 기능으로 남았지만 완전 자동 육성은 구현하지 않았습니다.
- 위치/화면 템플릿은 LOCALAPPDATA/UmaTrainerKR 아래에만 저장합니다. 서버로 전송하지 않습니다.
- 캐릭터/스탯/스킬에 대한 가상 수치가 실제 게임 결과인 것처럼 기록되지 않습니다.

[개발 및 배포]
Windows_EXE_빌드.bat, Windows_실시간도우미_EXE_수동빌드.bat 또는
.github/workflows/windows-exe.yml (수동 실행)에서 EXE를 빌드하도록 설정되어 있습니다.
이 ZIP에는 직접 빌드된 Windows 설치파일이 없습니다.
한국어 OCR을 사용하려면 별도의 Tesseract 한국어 언어 데이터가 필요합니다.
