Uma Trainer KR V0.4 R4 - Windows 설치형 배포 준비 소스

추가: 스크린샷 ROI 지정, 9개 숫자 OCR 후보 추출(별도 Tesseract 필요), 수동 검수/적용,
화면 해시/검수 내역 저장, 합성 테스트 예제, 51개 자동 테스트.

실행: Python 3 + Pillow가 있는 개발 환경에서 '실행.bat'.
Windows 사용자에게 배포할 EXE/Setup.exe는 GitHub Actions 'workflow_dispatch'를 실행하여 생성해야 함.
자동 배포/자동 커밋 없음. Windows EXE는 이 환경에서 아직 빌드하지 않음.

중요: 기존 R3 연구자료 유지. 한국 우마무스메 원본 스크린샷 검증 0건.
OCR 결과는 수동 확인 필요. 챔미·리오히 수치 추천은 여전히 실험판.
자세한 내용: docs/R4_기능_검증보고서.md
