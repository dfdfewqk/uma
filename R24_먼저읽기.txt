Uma Trainer KR R24 — 게임 업데이트 중 안정성 보강 / Windows 첫 테스트 준비

[현재 구현된 것]
- R23 기능과 기존 학습/코스/훈련 엔진을 보존했습니다.
- 게임 창이 사라지거나, 변경되거나, 이동/크기 변경되면 과거 OCR 수치 및 추천 문구를 즉시 폐기합니다.
- 화면 인식 결과가 늦게 도착하더라도 다른 창·레이아웃으로 전달하지 않습니다.
- 현재 화면이 훈련 화면이 아니라면 훈련 화면 OCR 좌표를 이용하지 않습니다.
- 게임이 비활성화되었거나 도우미 자체가 게임 일부를 가리고 있으면 읽기를 보류합니다.
- R23 검수 폴더의 이미지 내용 또는 ROI 설정이 이후 변경되면 기존 OCR 후보/검수 사용을 중단합니다.
- R24에서 생성하는 새 검수 목록은 이미지와 ROI 설정 SHA-256을 모두 기록합니다.
- 합성 화면 오류 테스트 외에는 실제 한국 서버 인식 정확도 검증을 주장하지 않습니다.
- 자동 클릭은 여전히 비활성화입니다.

[Windows에서 처음 시험할 순서]
1. UmaTrainerKR_Companion.exe 실행 후 PC 게임 업데이트가 끝났는지 확인.
2. 게임은 창 모드로 설정하고 게임 창 옆에 도우미가 위치하는지 확인.
3. 도우미가 게임 일부를 가리는 경우 창 크기를 줄여 두 창이 겹치지 않게 배치.
4. 도우미 창 감지, 화면 종류 및 OCR 후보가 갱신되는지 확인 (추천 아님).
5. R22 실게임 점검 창에서 같은 턴의 일반 훈련 5종을 각각 선택해 화면 캡처.
6. R23 오프라인 점검에서 캡처 5장과 ROI 파일을 불러와 수치 비교.
7. 일부 OCR 후보가 잘못되거나 빈칸이면 해당 필드만 직접 수정해 검수.
8. 다른 화면으로 이동하고, 게임 창 크기를 바꾸거나 닫아서 이전 OCR 수치가 남지 않는지 확인.
9. 오류 발생 시 R23 진단 JSON을 저장하되 개인 정보가 포함됐는지 검토 후 공유.

- 모든 훈련 선택지를 자동으로 열어 캡처: 안 됨
- 스킬 추천이 실제 구매 버튼에 자동 표시: 실게임 미검증
- 자동 클릭으로 전체 육성: 안 됨
- 실제 육성 영상 데이터 대량 학습/검증된 승률 모델: 안 됨
- Windows exe/설치파일 자체: 현재 Linux 환경에서 생성·검증하지 못함
- Tesseract OCR 실행 파일: 일반적으로 별도 설치 필요
