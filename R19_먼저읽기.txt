UMA TRAINER KR V0.19 — 게임 위 표시 / 옆 육성 정보창
===================================================

이번 버전은 R17 연구 엔진과 R18 실시간 화면 감시를 보존하고,
게임 위에는 짧은 선택 표식, 게임 옆에는 목표 스탯·필수 스킬 등 상세 정보를 표시하도록 UI를 분리했습니다.

개발자/시험 실행: Python + Pillow 환경에서 `실행.bat` -> 앱의 `게임 동반자 R19` 탭.
1) 우마무스메 PC 창에서 `창 찾기` -> `감시 시작`
2) `게임 위 표시 + 옆 정보창` 클릭
3) 훈련/스킬 화면을 선택 -> 스크린샷 미리보기의 항목 위치 클릭 -> 항목 이름 입력 -> 위치 저장
4) 현재 게임 화면 종류를 확인했다면 체크. 표시된 좌표는 사용자가 등록한 값임.

**중요:** 이 버전은 실제 게임 화면에서 눌러야 할 버튼이나 스킬을 자동 찾지 않습니다.
화면 좌표만 수동 보정하며, 현재 R6/R12 자료가 없으면 추천을 보류합니다.
게임 위 표시는 Windows 전용이며 클릭 통과 방식은 Windows 실PC에서 검증 전입니다.
자동 클릭/완전자동 육성은 R19 기능이 아닙니다.
배포용 EXE는 `Windows_EXE_빌드.bat`를 Windows에서 수동 빌드해야 합니다.
기존 `companion.py`는 R18 호환 도우미 시제품이며, 이번 R19 편집은 `app.py`에 연결되어 있습니다.
