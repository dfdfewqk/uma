Uma Trainer KR R23 · 무인도 한국 서버 · 오프라인/실게임 첫 테스트판

이번 버전은 기존 R22의 '게임 창 캡처 + 사용자가 훈련 수치 확인' 기능을 보존하고,
게임을 실행하지 않아도 합성 스크린샷 5장으로 오류를 점검할 수 있는 도구를 더한 버전입니다.
R23은 한국 서버 게임을 이미 자동 조작하거나, 최적 육성 추천을 학습했다는 의미가 아닙니다.

■ 지금 (우마무스메 업데이트 중) 가능한 검사
1) 개발용 Python 환경: offline_replay_ui_r23.py 실행
   일반 사용자용 Windows 설치파일은 수동 Windows 빌드가 필요합니다.
2) '합성 샘플 사전점검'을 클릭 → 훈련 5종의 화면과 OCR 후보/오류 확인
3) 하나의 훈련 행을 선택 → OCR 후보를 입력칸에 복사 → 이미지와 수치 확인
4) 체력 변화 등 빈칸을 직접 입력 후 '이 훈련 검수 완료'
5) 'PC 연결 환경 점검'을 눌러 OCR·버튼 탐지·보정 상태 확인
6) 진단 JSON 저장 (스크린샷, 파일 경로, 창 제목, 개인 정보 미포함)

■ 게임 업데이트 후 첫 확인
1) 게임을 창 모드로 실행하고 UmaTrainerKR_Companion 시작
2) '실게임 훈련 점검 · R22'에서 게임 창을 선택하거나 자동 감지 상태 확인
3) 훈련 5종을 게임에서 하나씩 직접 눌러 R22에서 스크린샷 저장
   (훈련 버튼을 살짝 눌러 예상 상승량만 본 상태의 화면; 게임 진행 확정 전)
4) R22에서 숫자 영역(스탯 상승량/스킬 Pt/실패율)을 한 번 보정 후 저장
5) 'R23 · 게임 없이 사전점검' → '실제 캡처 5장 묶기'
   같은 턴의 5장과 OCR 보정 파일이 새 로컬 폴더에 복사됨
6) OCR 숫자와 화면이 맞는지 직접 확인, 체력 변화까지 확인 후 훈련 비교
7) 잘못 인식한 항목이 있으면 오류 내용을 확인하고 진단 JSON 저장

■ 제한 / 주의
- 일반 훈련 5개를 비교하지만 휴식/외출/레이스까지 포함한 최적 행동은 아닙니다.
- 화면 OCR 후보는 정확한 결과로 자동 확정되지 않습니다.
- 합성 스크린샷은 ML 학습 데이터나 한국 서버 인식률로 사용하면 안 됩니다.
- 게임 클릭·육성 자동화는 들어 있지 않습니다. 계정과 게임 이용 규칙도 확인해야 합니다.
- 현재 Windows EXE 자체는 이 환경에서 빌드하거나 실제 한국 서버에서 검증하지 못했습니다.
- 초기 Python 개발 실행에는 Python/Pillow/OpenCV/Tesseract 등이 필요할 수 있으나,
  수동 Windows 빌드 설정은 Python이 필요 없는 EXE를 만드는 용도입니다.
- OCR 실행에는 별도의 Tesseract가 필요합니다. 설치되지 않으면 수동 검수는 가능합니다.
- 기본 기능은 로컬 처리만 수행하며 스크린샷을 외부 서버에 자동 업로드하지 않습니다.
- 진단 결과·캡처에 개인 정보가 들어갈 수 있으니 공유 전 본인이 검토해야 합니다.
