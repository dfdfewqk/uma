Uma Trainer KR V0.21 R21 — 버튼 자동 위치 탐지

# R21 — 한국 우마무스메 훈련 버튼 위치 자동 탐지 (개발용)

## 변경된 사용자 흐름
- 기본 사용 UI는 작은 `companion.py` 앱. Windows 설치형은 `UmaTrainerKR_Companion.exe`로 시작.
- 상세 설정 앱(`UmaTrainerKR.exe`)에서 훈련 화면의 버튼 중앙을 한 번 눌러 **R21 버튼 특징 이미지**를 등록.
- 같은 훈련 화면을 다시 볼 때 등록된 모양을 제한 영역 내에서 재탐색하고, 두 프레임 연속 같은 위치에서 확인된 버튼만 인정.
- R20에서 화면 유형이 '훈련'으로 확정되고 R6에서 **현재 턴의 훈련 추천**이 검수된 경우에만 버튼 위 추천 표식이 나타남.
- 게임 옆 정보창은 R11 목표 스탯·필수 스킬 등을 계속 사용하며 R12 스킬 표시는 기존 OCR 정책 유지.
- 장면 변경, 화면 크기 비율 변경, 동일 모양 복수 발견, 불확실한 탐지, 창 비활성화 시 표식을 숨김.

## 시범 사용 순서
1. Windows 우마무스메 실행 후 작은 도우미의 게임 감지 확인.
2. '상세 설정·자료 관리 열기'에서 실시간 게임 동반자 탭 이동.
3. 게임 창을 선택하고 감시 시작. R20 기준 화면 특징 2개를 서로 떨어진 위치에 등록.
4. 실제 훈련 화면에서 훈련 버튼 중앙을 클릭하고 R21에서 버튼 종류 선택 → 특징 등록. 필요한 버튼 각각 등록.
5. 이후 장면과 버튼이 둘 다 인식되는지 확인. R6 추천 데이터가 없으면 버튼 탐지 정보만 보이고 추천 표식은 보류.

## 실제 완료 범위
- 템플릿 패치의 해시 검사, 해상도 비례 검색, 독립 후보간 중복 차단.
- 두 프레임 일치, 사라짐/다른 장면/이전 창 데이터 무효화.
- UI와 배포 설정 연동. 기존 R1~R20 보존.
- **합성 테스트 화면에 대해서만 인식 동작 검증. 실제 한국 서버 게임 영상으로 검증하지 않음.**
- 별도의 '자동육성 판단 → 실제 클릭' 연동 없음. 이전 버전의 사용자가 명시 승인하는 1회 클릭 시험은 자동 육성이 아님.

## 남은 검증
- 한국 서버 훈련 버튼 6종과 다중 서포트 배치, 시설/훈련 변형 화면 자료 수집 및 캘리브레이션.
- Windows 10/11 DPI 100~150%, 여러 모니터, 창 크기 변경 후 정확도 검증.
- 휴식/레이스/외출, 무인도 시설, 이벤트, 스킬 구매 목록 실게임 인식 정확도 검증.
- 한국 서버 UI 클릭 간섭 및 Windows 빌드/설치 테스트. 외부 Tesseract 한국어 OCR 필요.
- 인식 성능을 일반 게임 화면 데이터로 검증 전까지 자동 클릭을 추천 엔진과 연결하지 않음.

## 패키징
- `Windows_EXE_빌드.bat`: 개발용 전체 앱과 작은 도우미 EXE 수동 생성.
- `.github/workflows/windows-exe.yml`: 수동 트리거만 지원, Release는 선택적(기본 꺼짐).
- 설치 파일용 `UmaTrainerKR_Setup.iss`는 작은 도우미를 기본 시작 앱으로 설정.
- 이 ZIP에는 미리 빌드된 Windows EXE가 들어 있지 않음.
