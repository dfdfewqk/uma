Uma Trainer KR V0.7 R7 — 연구·실험용 Windows 육성 도우미
============================================================

[중요]
- 한국 서버 Windows PC용 / 챔피언스 미팅과 리그 오브 히어로즈 전용
- 무인도 시나리오(일본 2025-06-30 밸런스 조정 후)부터 개발
- 실제 한국 서버 수치, 추천 정확도, ML 모델, 자동 육성 기능은 아직 검증·완성되지 않았습니다.
- 게임 클라이언트에 직접 접속하거나 게임을 조작하지 않습니다.
- 가중치는 모두 실험값이며 성공·고점·승률·최적 행동을 보장하지 않습니다.

[현재 개발본 실행]
1. Python 3.12 이상 설치 (일반 사용자 배포 시에는 Python 설치가 필요하지 않은 EXE 빌드 예정).
2. 터미널: python -m pip install -r requirements.txt
3. 실행.bat 또는 python app.py
4. Tesseract가 있으면 OCR 후보를 확인할 수 있으나 필수는 아닙니다. OCR 값은 사용자 검수가 필요합니다.

[새로운 ⑧ R7 무인도 건설 계획 사용법]
1. ① 육성 목표에서 챔미/리오히·거리·목표 스탯을 설정합니다.
2. ② 턴 분석에서 현재 스탯·실제 시설 Lv·티켓 수·발전 Pt를 입력합니다.
3. ⑧ R7 탭에서 현재 건설 회차(1~5), 터커 브라인의 Lv 등급을 선택합니다.
4. Lv3 이상인 시설의 본능/기교 분기를 확인하고, 해당 시설의 분기를 선택합니다.
5. 가능하면 서포트 타입별 장수와 성장률 우세 스탯도 기록합니다(모르면 비워 둡니다).
6. 평가회 목표 발전 Pt·남은 턴·예상 획득량을 아는 경우에만 입력합니다.
7. 현재 시기가 시니어 9월 전반 이후면 티켓 상한 체크박스를 켭니다.
8. '시설 건설 경로 비교'를 누르면 현재 시설에서 남은 회차까지 3개 계획 후보와
   평가회 부족량·티켓 관련 참고 문구가 표시됩니다.
9. 최종 결과를 JSON으로 내보낼 수 있습니다. 확인한 게임 화면과 비교하며 자료를 축적하세요.
10. 이 계획은 실제 승률·성장량 예측이 아닌 실험적 휴리스틱 비교입니다.

[기존 ⑦ R6 전체 행동 비교 사용법]
1. ① 육성 목표에서 챔미/리오히·거리·목표 스탯을 확인합니다.
2. ② 턴 분석에서 체력, 스탯, 남은 턴, 섬 트레이닝 티켓 등을 입력합니다.
3. ⑥ R5 훈련 수치 검수에서 5종 일반 훈련(티켓 있으면 섬 훈련)의 스탯 상승량과 실패율 등을
   수동으로 확인한 뒤 ② 턴 분석으로 전달하거나, ②에서 직접 확인한 수치를 입력합니다.
4. 휴식/외출/레이스도 ② 화면에서 각각 선택하여 기대되는 체력 변화/스킬 Pt/발전 Pt 등을
   직접 확인한 후 '이 행동의 결과를 확인함' 체크하고 '현재 행동 값 적용'을 누릅니다.
5. ⑦ R6 탭의 '확인된 수치가 있는 행동 → 가능 지정'을 누릅니다.
6. 게임에서 이번 턴 선택할 수 없는 행동은 R6에서 '불가'로 명시하고 '상태 적용'을 누릅니다.
   수치가 미확인인 행동은 '미확인'으로 남겨야 하며, 전체 추천은 보류됩니다.
   섬 티켓 0개일 때 섬 트레이닝은 자동으로 비교에서 제외합니다.
7. 'R6 전체 행동 비교'를 누르면, 확인된 현재 턴 행동의 상대 점수와 근거가 표시됩니다.
8. R6 분석 JSON 저장은 선택입니다. 이는 실험 데이터이며 ML 정답 데이터가 아닙니다.
9. ② 화면에서 실제 선택한 행동을 지정하고 턴을 저장하면, 유효한 R6 검수 결과도 SQLite에 함께 보관합니다.
   다음 턴의 선택지는 다시 확인해야 하므로 이전 턴 결과는 자동 초기화합니다.

[R8 사용 방법]
1. ① 육성 목표 / ② 턴 분석에서 현재 경기 조건, 시설 레벨, 티켓 수를 입력합니다.
2. ⑧ R7 무인도 시설 계획에서 현재 건설 회차와 터커·분기를 확인하고 건설 경로를 계산합니다.
3. ⑦ R6 종합 행동 비교에서 전체 행동을 검수하면 (선택 사항) 섬 훈련의 실제 입력 상승량을 R8에서 함께 볼 수 있습니다.
4. ⑨ R8 시설·훈련 연계 탭에서 실제 우정 훈련 발생 인원을 시설별로 모두 확인하고 분석합니다.
5. 현 시설 및 R7 건설 후보별 우정 훈련 적용 시설, 미건설 제외 시설, 해변의 집 조건을 검토합니다.
6. 원한다면 R8 결과를 JSON으로 별도 저장합니다. 새 턴/설정에서는 다시 검수해야 합니다.

R8은 미래 동일한 서포트 배치를 가정한 '시설 적용 조건' 비교이지, 미래의 실제 스탯 상승량이나 챔미 승률을 예측하지 않습니다.

  불러온 뒤에는 필수 스킬을 다시 확인하고 평가회 남은 턴을 반드시 새로 입력하세요.

[R12 새 기능 — 코스/마장 조건별 육성 시작 전·스킬 구매 도우미]
- ① 육성 목표에서 '육성 시작 전 코스별 스탯·추천 스킬 미리보기'를 누르거나 ⑬ 코스·스킬 탭을 선택합니다.
- 초기 프리셋 4개: 도쿄 잔디 2400m / 한신 잔디 2200m / 나카야마 잔디 2500m / 교토 잔디 3200m.
- 다른 코스는 '직접 입력'을 선택하세요. 검증되지 않은 종반 지형은 미검증으로 판단합니다.
- 각질, 대회 종류, 계절, 날씨, 마장 상태를 지정하고 '경기장 조건 추천 미리보기'를 눌러 육성 전에 기본 추천을 확인하세요.
- 기존 사용자가 설정한 목표 스탯 5종을 표시하되 *정확한 코스별 권장 수치는 검증 후에만* 추가합니다.
- 스킬 구매 화면에서는 게임에서 직접 확인한 구매 후보를 한 줄씩 `스킬명 | 실제 Pt | 구매가능` 형식으로 입력 후 '스킬 구매 목록 분석'을 누릅니다.
- 관측 경기 기록이 있는 경우에만 `스킬명 | 실제 Pt | 구매가능 | 경기수 | 발동수 | 유효발동수` 를 입력할 수 있습니다.
- 결과의 녹색 행은 확정 조건에 맞거나 강한 검토 후보, 노란 행은 추가 검토, 붉은 행은 조건 불일치 또는 비효율 후보입니다.
- 실제 경기 표본이 없는 일반 스킬의 발동률과 실제 효율은 수치로 **산출하지 않습니다**.
- 이 프로그램은 한국 서버의 스킬 화면을 자동 스캔하거나 게임 화면 위에 아이콘을 표시하지 않습니다. R12는 *게임에서 보이는 스킬을 수동 입력하는 별도 앱 화면*입니다.
- 스킬의 효과 크기, 지속시간, 순위 조건의 상대 빈도, 한국 서버 패치 적용/입수 가능 여부를 검증해야 실제 승률 최적화가 가능합니다.
- 저장한 R12 JSON은 로컬 검토 기록이며 R9의 검수된 실측 데이터셋이나 ML 학습 데이터에 자동으로 합쳐지지 않습니다.
- 근거와 제한 사항: docs/R12_코스스킬_설계및제약.md

[R13 새 기능 · 2026-10-15]
- ⑭ 대회·인자 탭: 일본 2025년 7~10월 무인도 수정 후 개최 사례 4건을 선택하고 도주/선행/선입/추입을 지정합니다.
- 본육성: 하이랜더 중심 서포트 편성 후보 6장 + 대체 후보. 인자작: 별도 힌트 확보 카드 후보.
- 원하는 경우 [선택한 카드만 보유한 것으로 간주]를 켠 뒤 카드 목록을 여러 개 선택하고 [추천 분석]을 누릅니다.
- 계승 부모·목표 스킬·확인된 일부 각질 스탯 참고값·출처가 하단에 나옵니다.
- [코스·스킬 탭으로 전달]은 ⑬ R12 화면으로 경기장·날씨·각질을 넘기며 게임을 조작하지 않습니다.
- 일본 서버 2025년 역사 기록이며 한국 서버 대회 일정, 미출시 카드 상태는 보장되지 않습니다. ML·정확한 발동률/승률 예측 기능 아님.
- 근거 및 한계: docs/R13_데이터_조사_개발보고서.md

[R14 업데이트: 부모·조부모 인자작 및 미래시]
① 목표 화면의 '부모·조부모·대회 미래시 (R14)' 버튼 또는 ⑮ 계승·미래시 탭에서,
대회/각질/육성 캐릭터를 선택하면 부모 2개 슬롯·조부모 4개 슬롯의 근거 기반 후보가 표시됩니다.
보유 육성마를 쉼표로 입력하면 해당 후보만 사용하며, 조건에 맞는 후보가 없으면 미확정으로 둡니다.
아래에 한국 서버 일정 확인 상태와 준비 마일스톤을 표시합니다.

프로그램에 ML/게임 내 자동 인자작/공식 일정 자동 갱신 기능은 아직 없습니다.
