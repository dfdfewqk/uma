Uma Trainer KR V0.22 (R22) · 실게임 첫 테스트 안내
==========================================

1. 이 ZIP은 Windows EXE가 아니라 소스/빌드 준비본입니다. Python을 설치하지 않고
   프로그램을 사용하려면 Windows에서 빌드한 UmaTrainerKR_Setup_0.22.0.exe가 필요합니다.
   Windows GitHub Actions 수동 빌드(workflow_dispatch)를 실행하거나 Windows_실시간도우미_EXE_수동빌드.bat를 실행하세요.
   첫 번째 방법은 사용자 PC에 Python이 필요 없고, 두 번째 방법은 빌드할 PC에 Python이 필요합니다.
   이 환경에서는 Windows EXE를 직접 실행 검증하지 못했습니다.

2. 우마무스메 한국 서버 PC 클라이언트를 실행하세요. 화면 모드는 먼저 창 모드를 권장합니다.
3. UmaTrainerKR_Companion.exe → '실게임 훈련 점검 · R22'를 누르거나
   UmaTrainerKR_GameTest.exe를 실행하세요.
4. [게임 창 다시 찾기]를 누르고 미탐지 시 [게임 창 직접 선택]에서 정확한 게임 창을 지정하세요.
5. 게임에서 스피드 훈련 탭만 선택합니다. 훈련 확정 버튼은 누르지 마세요.
   R22에서 훈련 이름 '스피드'를 고르고 [현재 게임 화면 캡처]를 누르세요.
6. OCR을 사용하려면 Windows에서 Tesseract-OCR(영어 숫자 인식)을 별도로 설치하세요.
   설치하지 않아도 숫자는 직접 입력할 수 있습니다.
   OCR 보정: 오른쪽에서 '스피드 상승' 등 항목 선택 → 왼쪽 화면의 숫자만 드래그.
   5종 상승량/스킬 Pt 상승/실패 확률의 7개 영역을 한 번 보정합니다.
   OCR 후보는 반드시 실제 화면과 대조하고 잘못된 값을 직접 수정하세요.
   체력 변화(- 수치)는 항상 직접 확인하여 입력해야 합니다.
7. [이 훈련 검수 완료] 후 같은 턴에서 스태미나, 파워, 근성, 지능 탭을 차례로
   눌러 화면을 캡처하고 7개 숫자와 체력 변화를 확인합니다.
   섬 트레이닝이 가능한 경우에는 섬 티켓 수를 입력하고 해당 화면도 검수하세요.
8. [검수된 훈련 비교]를 누르면 현재 입력한 훈련끼리 실험 점수가 표시됩니다.
   휴식·레이스·외출 미포함, 최적 육성/승률/도축 판단 검증 전입니다.
9. 화면 인식에 문제가 생겼다면 [연결 환경 진단]을 누르고
   [현재 캡처 PNG 저장], [진단 기록 JSON 내보내기]를 수행한 뒤 공유해 주세요.
   게임 닉네임 등 개인 정보가 보이는 부분은 공유 전 가려주세요.

테스트용 가상 화면: examples/r22_mock_1.png ~ r22_mock_5.png
(이 파일은 실제 한국 게임 화면이 아닌 OCR 동작 검증용입니다.)

**사용자용 실시간 도우미는 아직 훈련 5종 전자동 OCR 수집 및 자동 클릭을 수행하지 않습니다.**
이번 R22는 실제 게임 화면을 확인하고 인식 정확도를 진단할 수 있는 '현장 검증판'입니다.
R1~R21 원본 기능/데이터를 삭제하지 않았습니다. GitHub 자동 커밋/자동 배포 없음.
