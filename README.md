# Uma Trainer KR

한국 서버 우마무스메 Windows PC 육성 보조 프로그램의 개발 저장소입니다.

## 목표
- 챔피언스 미팅 및 리그 오브 히어로즈 실전용 육성
- 무인도 시나리오부터 지원하며 시나리오별 규칙은 분리
- 게임 화면 위에 추천 훈련·스킬 표시, 게임 옆에 목표 스탯·필수 스킬·상세 근거 표시
- 화면 인식, 기록 검수, ML 모델 관리 기능을 단계적으로 개발

## 개발 현황 (R28)
- 연구용 판단 및 기록 시스템, 훈련 OCR 검수, 실시간 추천 전달, 오버레이 프로토타입 구현
- 실제 한국 서버 PC 화면 인식과 클릭 통과 UI는 아직 실기기 검증 필요
- **실제 게임 자동 클릭·완전 자동 육성 미구현**
- **검증된 실전 ML 학습 데이터 부족**
- Windows 설치 EXE 생성 및 설치 검증 전

## 개발자 확인
```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -q
```

Windows 사용자용 EXE는 `.github/workflows/windows-exe.yml` 수동 워크플로에서 빌드하도록 설계했습니다.
자동 빌드/자동 배포 트리거를 추가하지 않습니다.

## 주의
작업물은 연구·개발용입니다. 게임 화면 인식 및 자동 제어의 실제 호환성이나 계정 안전성을 보장하지 않습니다.
