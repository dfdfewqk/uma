Uma Trainer KR R28 — 실게임 훈련 검수 결과 ↔ 게임 옆 도우미 ↔ 게임 위 표식 연결

실제 게임 테스트 절차 (Windows)
1) 한국 서버 우마무스메를 창 모드로 실행합니다.
2) 설치형이 준비됐다면 UmaTrainerKR_Companion.exe를 실행합니다.
   개발 환경에서는 python companion.py 실행이 가능합니다.
3) 상세 설정에서 기존 R20 훈련 화면 특징을 등록하고 R21 훈련 버튼 이미지(최소 추천할 종류)를 등록합니다.
4) 도우미의 '실게임 훈련 점검 · R22'를 열어 동일 턴에서 훈련 다섯 종류의 화면을 각기 캡처합니다.
   게임 창이 활성화된 상태여야 하며, 이미지 파일 불러오기는 화면 위 추천 근거로 사용하지 않습니다.
5) 모든 필수 숫자를 검수한 후 '검수된 훈련 비교'를 눌러 내용을 확인합니다.
6) 'R28 · 이번 턴 추천을 게임 위에 표시' 버튼을 누릅니다.
7) 게임으로 돌아가 훈련 화면을 엽니다. 등록한 버튼의 모양과 화면 종류가 반복 확인되면,
   도우미 창과 게임 화면 위에 훈련끼리 비교한 후보 1순위가 잠깐 표시됩니다.
8) 게임에서 다음 턴으로 넘어가기 전 'R28 · 화면 위 추천 취소' 또는 '다음 턴 시작'을 사용합니다.

주의 및 현 상태
- 화면 위 강조는 검수된 다섯 훈련끼리 비교한 실험값이지, 휴식/레이스/외출을 포함한 전체 육성의 최적 선택이 아닙니다.
- 이번 버전은 자동 클릭을 수행하지 않으며 스킬 구매창 자동 표시는 아직 미완성입니다.
- 추천 전달 파일은 로컬 PC에만 저장되며, 생성 후 최대 2분만 유효합니다.
- 창·해상도·화면·포커스가 바뀌면 이전 표시는 무효화됩니다. 화면 전환을 감지하지 못할 수 있어, 턴 전환 때는 반드시 수동 취소하세요.
- 실제 한국 서버의 화면 자동 인식 정확도, Windows EXE 및 게임 위 클릭 통과는 검증되지 않았습니다.
- 소스 자동 테스트는 실전 품질을 증명하지 않습니다.
- 나기님 영상 https://youtu.be/L7zlNFfm8aY 의 자막은 아직 실제 확보되지 않았으며 R27 교차검증 연구자료는 보존했습니다.
