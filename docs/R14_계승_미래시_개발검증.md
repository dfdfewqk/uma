# Uma Trainer KR V0.14 / R14

기준 자료 조사: 2026-10-15. 국내 서버의 대회 준비 기능이며 온라인 조회나 자동 갱신 기능은 아직 없음.

## 포함된 개발 내용

- 코스·각질별 R13 출처에 등장한 계승 고유기 중심 부모 2명 후보 자동 배치
- GameWith 인자작 공략에 등장한 범용 후보 중심 조부모 4명 배치
- 같은 캐릭터의 의상 차이를 일부 정규화하고, 육성 대상·부모·조부모 간 이름 중복을 기본 제외
- 보유 우마무스메 이름 목록을 입력하면 없는 후보를 제외하며, 부족한 슬롯은 공란으로 남김
- 동일 캐릭터의 전 의상 전체를 인지하는 완전한 한국 서버 DB는 **아직 없음**
- 청/적/백/녹 인자의 목표 종류 안내 (캐릭터가 실제 해당 인자를 보유하는지 확인하지 않았음)
- 각 대회의 **일본 실제 개최일**, **한국 확인된 날짜(외부 2차 출처)**, **한국 예상 월(미확정)** 분리
- 일정 확인된 대회만 42·35·21·14·3일 전의 가상 마일스톤 자동 생성
- 사용자 변경 없이 R1~R13 데이터와 SQLite 기록은 보존
- 추천과 일정 결과 JSON 내보내기. 기존 파일 덮어쓰기 금지

## 자료 출처와 적용 상태

- 한국 서버 2026년 11월 13~19일 한신 2200m 챔미: GameTora 및 swallow91 블로그의 일정 표기. **게임 내 공식 공지 최종 확인 필요**.
- 2026년 12월 삿포로 2600m LoH, 2027년 1월 교토 2000m 챔미, 2027년 2월 니가타 1200m 챔미: 일본 대회 약 16개월 후라는 전제를 따르는 **추정 월**만 제공. 해당 날짜를 확정하지 않음.
- 인자작: GameWith의 '因子周回のやり方とおすすめキャラ', 디시 공지/육성 준비 과정 참고.
- 일본 서버 2025년 7~10월 대회 정보는 R13에서 재사용.
- 자세한 URL: `research/r14/lineage_and_calendar.json`의 `sources`.

## 정확성 제한

이 기능은 연구에 근거한 **후보 우선순위 규칙 기반 추천**이며, 학습된 ML 모델이 아니다. 상성 계산값, 특수 스킬의 발동률, 가계도 성능 순위, 인자 승계 확률을 계산하지 않는다. 개별 우마무스메의 정확한 G1 전적, 현재 보유 인자, 서포트 풀, 한국 서버 실장 여부도 알 수 없다. 특히 조부모 후보는 범용 풀일 뿐 대회별 검증 우승 조합이 아니다.

실제 화면 인식과 Windows EXE 빌드 및 Windows 실게임 테스트는 아직 실행하지 않았다. PyInstaller/수동 Actions 설정만 보존·갱신.

## 사용

1. 프로그램에서 `① 목표` → `부모·조부모·대회 미래시(R14)` 버튼 클릭 또는 `⑮ 계승·미래시` 탭 선택
2. 일본 참조 대회 4종에서 대상 선택, 각질 및 육성 캐릭터 입력
3. 보유 육성마가 있으면 한국어 이름을 쉼표로 입력하고 재분석
4. 화면 하단 미래시 일정/준비 단계 및 출처 확인
5. 결과는 `JSON 저장`으로 파일을 남겨 재검토. 프로그램 자체가 원격 일정을 자동 갱신하거나 알림을 설정하지는 않음

차기 단계: 확정 한국 서버 대회 일정의 갱신 기능, 캐릭터별 상성 DB, 보유 인자/힌트 입력, 부모·조부모·목표 우마무스메 계보 완전 판정, 자체 유효 스킬 중복 검사.
