# R60 — 영상 검증 전 가능한 시작 선택 상태 판독 보강

## 원본·자료 상태
- GitHub 기준 R59 `59e294253ded574a1061ca6a8ff7e0b2c1af912b`; R51 백업 브랜치 및 Windows 사용자 프로필 보존.
- 사용자가 제공한 실제 MP4 3개는 업로드 존재/크기만 확인됨. 현재 실행기 오류로 영상을 재생/프레임 추출하지 못해 **실제 선택 버튼·시간·경로를 확인하지 못했다**.
- 전달된 YouTube 영상도 웹에서 실제 재생/자막 확인이 불가능해 일반 육성 선택 순서를 사실처럼 만들지 않았다. 음성 처리 없음.

## 실제 적용한 선택 판독 변경
- 기존 R59의 일반(normal)·이벤트(event) 분기와 화면별 버튼 템플릿/고유 표식은 그대로 사용.
- 이제 선택지 등록 시 **선택 중 표식(선택 사항)** 을 별도 영역으로 검수 등록할 수 있다. 실제 게임에서 해당 옵션이 선택된 상태여야 하며, 해당 상태 여부를 사용자가 체크한 경우에만 저장된다.
- 등록된 선택지와 선택 표식이 두 번 연속 정확히 일치한 경우에만 `selected_choice`가 확인 후보로 표시된다. 서로 다른 선택 표식이 동시에 검출되면 보류한다.
- 예전 R59 JSON은 새로운 선택 표식 항목 없이도 로딩된다. 등록 데이터 덮어쓰기 불허는 유지.
- 도우미에서는 **보이는 선택지**와 **선택 중인 선택지**를 구별한다. 어느 쪽도 자동 클릭/계승 결정/유료 결제 승인을 뜻하지 않는다.

## 여전히 미완료
- 일반 유튜브 시작 영상과 현재 이벤트 시작 영상의 **실제 버튼 선택 순서**.
- 실제 화면 픽셀/버튼 좌표/선택 표시 모양을 검수한 한국 서버 프로필 작성.
- 시작 분기 및 캐릭터·서포트·계승을 자동으로 선택하는 클릭 기능.
- 실제 Windows 실행, OCR 정확도, Python 전체 테스트. 코드 단위 테스트가 추가되었으나 이 환경에서 실행기 오류로 실행하지 못함.

## 향후 근거 검수 기준
영상 내 시작 화면만 시각 확인한 뒤 단계/선택지/프레임 타임스탬프/분기를 작성한다. 육성 실패 원인, 포기 판단, 사운드는 분석 대상에서 제외한다.
