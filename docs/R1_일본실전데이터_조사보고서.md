# JP 무인도 수정 후 육성 사례 — 1차 조사보고서

**대상:** 무인도 시나리오, 챔미/리오히 실전 육성, 2025-06-30 변경 이후. **결과:** 문헌·공개 영상 소개 기반 1차 자료집. 개별 턴 판독과 ML은 아직 시작하지 않음.

## 게임 규칙과 전략 분리

- 밸런스: 스태미나·파워·근성·지능 시설 강화, 해변의 집의 복수 우정 시설 효과 추가 [S001][S007].
- 초기 운영: 주니어/클래식에 스킬 힌트, 레이스 출전 스킬 Pt와 인연도 가치를 비교 [S006].
- 섬 트레이닝: 다수 우정의 효율이 높지만, 인연이 덜 찬 초반·티켓 만료·다음 티켓까지 남은 턴에 따라 예외 판단 [S006].
- 건설: 성장률·서포트 카드·목표 스탯별로 최종 시설 배분이 실제로 달랐음 [S014][S017].
- 스킬: 많이 모은 스킬 Pt 자체보다 실제 유효 스킬 힌트, 필수 금스킬 완주, 코스 조건이 중요 [S014][S017].

## 확인된 사례

- S014: 7월 2200m 챔미 후보 젠틸 육성에서 스탯 일부 상한 및 스킬 Pt 6400+ 보고. 사용 가능한 스킬 부족을 본인이 지적. 실제 챔미 성능 미검증.
- S017: 2025-09 챔미 실전 보고 중 버번·젠틸·스틸 3명의 최종 시설 배분과 스킬 누락 결과가 다르게 기록됨. 스탯 좋지만 필수 금스킬 불완주 사례, 거리S/금스킬 다 달성했지만 스탯 부족으로 완주 후 출전 제외 사례 포함. 경기장 표기 상충.
- S018: 삿포로 2600m 리오히 후기에서는 최종 450점 손실을 기록. 이는 대회 점수 결과이며 개별 육성 턴에 대한 감독 라벨이 아님.
- S015: 건설 결정 실수 이후 재시작한 익명 댓글 발견. 표본 1이며 일반적인 도축 확률 추정 불가.
- S010: 영상 설명에서 US1 마야노 완주 및 턴 운영 의도 해설을 밝힘. 프레임별 실측 데이터는 아직 없음.

## 재시작(도축) 알고리즘 안전장치

1. '계속 / 주의 / 재시작 검토'의 정보 제공 수준으로만 작동한다.
2. 기분이나 일시적인 훈련 실패가 아니라 **남은 턴에서 목표 달성 가능성**을 중심으로 계산한다.
3. 보유 카드·캐릭터·챔미 vs LoH·플레이 시간이 다르면 포기 기준도 달라진다.
4. '완주 후 출전 제외', '실제 중도 포기', '경쟁 레이스 패배'를 반드시 다른 레이블로 보관한다.
5. 충분한 비교 사례와 성능 검증 전에는 자동 재시작/포기를 연결하지 않는다.

## 다음 데이터 확보의 순서

- 1순위: S010 챕터가 제공된 전 육성 영상(실제 화면을 턴별 검수).
- 2순위: S011 챔미용 육성 영상(실전 목표와 선택 이유).
- 3순위: S012 리오히 인자 작업 스트림, 추가로 LoH 실전 육성 영상 탐색.
- 4순위: 개인 리플레이/실제 프로그램 기록을 사용자 동의하에 수집. 현재 미확인 상태 수치 추측 금지.
