# R55 — 같은 턴의 훈련 5종 보상 후보 통합 수집 (5단계)

## 기준
- 이전 R54 main: \`9d5a02040527ce1873e913fe59c30b1b4e053046\`.
- R51 원본 백업 브랜치 유지. 기존 R48 미리보기 OCR, R49 실험적 자동 탐색, R50 스킬/TP, R53 장면 인식, R54 기존 영역 파일 및 육성 기록을 보존.

## 구현된 관측 경로
1. **R48**의 2회 일치 OCR로 수집된 스피드·스태미나·파워·근성·지능 5종의 미리보기 상승량을 각 훈련명에 따로 저장한다.
2. **R54**에 수동 보정 가능한 \`체력 소모\`, \`스킬 Pt 증가\` 숫자 후보를 추가한다. 단, 실제 해당 수치가 화면에 보이고 ROI가 검수된 경우에만 사용한다. 플레이어의 현재 스킬 Pt 보유량을 선택 훈련의 예상 스킬 Pt 증가로 사용하지 않는다.
3. 수치 인식 안정성의 범위를 **같은 게임 창 + 화면 크기/위치 + 턴 지문 + 현재 선택한 훈련명**으로 묶는다. 다른 훈련의 실패율·회복·Pt 수치를 오인해 전용하는 오류를 차단한다.
4. 신규 \`TrainingEvidenceCollector\`가 R48 5훈련 수치와 R54의 선택 훈련에 해당하는 실패율·체력 소모·스킬 Pt 증가 후보를 통합한다. 장면·턴·창이 변경되면 초기화한다.
5. 도우미에 '훈련 후보 스탯 N/5 · 실패율 N/5' 상태를 표시한다. 미확인 항목을 0으로 채우지 않고 \`None\`으로 남긴다. 이 자료는 \`game_input_allowed=False\`, \`decision_ready=False\`, \`ml_training_label=False\`이다.

## 아직 미구현 / 실제 한국 서버 증거 필요
- 우정 훈련 인원과 서포트 인연 게이지의 실제 그래픽 인식. 화면 자료가 없어 수치를 꾸며 넣지 않음.
- 실제 훈련별 체력 소모 및 스킬 Pt 증가를 화면에서 읽을 ROI 정확도.
- 실패율·5종 상승량 OCR 실게임 성공률 및 직후 결과 보상 검증.
- 이 후보만으로 R46 최적 판단을 통과시키거나 R49의 기존 **실험적 잠정 스탯합계 자동 클릭**을 검증 완료라고 표시하지 않음. R55는 **읽기 전용**으로 독립 추가되며 사용자의 이전 자동 입력 정책은 변경하지 않는다.
