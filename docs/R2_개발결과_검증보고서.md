# 무인도 실전 영상 데이터 수집 R2 — 개발·검증 보고서

## 1. 목표와 실제 범위

R1의 **문헌/메타데이터 기반 자료**와 게임 화면에서 확인한 **실측 자료**를 분리하기 위한 연구 수집 도구를 완성한다. 범위는 일본 서버 2025-06-30 밸런스 조정 이후 무인도, 챔미·리오히 실전 육성을 우선 대상으로 한다.

### R2가 실제로 수행한 작업

- R1의 25개 출처, 28개 근거, 9개 사례, 13개 가설, 12개 챕터 지점을 보존.
- 우선 검수 영상 목록 4개 등록. 이 중 인자작·평가점 영상은 챔미·리오히 실전 본육성과 구분.
- 12개 챕터의 원본 시점 링크 제작(`research/video_reviews/review_checkpoints.csv`). **실제 프레임을 본 것은 아님.**
- 로컬 프레임 샘플러: 영상 타임스탬프 지정, 일정 간격(최대 100장), 챕터 기반 추출 지원.
- Tkinter 검수 UI: 출처·패치 근거·실전 육성 목적·상태·선택 행동·선택 전후 화면 기록.
- 검증기: 잘못된 출처, 근거 없는 패치 확인, 누락된 로컬 이미지, 선택지와 클릭 행동 불일치, 중복 기록을 차단.
- 로컬 이미지의 SHA-256을 저장해 수정되거나 유실된 파일을 탐지.
- ML 학습이나 엔진 가중치 변경은 수행하지 않았고, 검수된 실제 턴도 **0개**임을 명시.

## 2. 실제 검증

| 검사 | 결과 |
|---|---|
| V0.1/V0.2/R1 포함 통합 테스트 | 31개 통과 (테스트 환경: Linux + Python 3) |
| 연구용 Tk GUI 생성 및 종료 | 성공 (가상 디스플레이에서 시험) |
| 로컬 ffmpeg 프레임 추출 | 임시 생성한 3초 테스트 영상에서 시점 0·1·2초 각각 1장 출력 성공 |
| R2 근거 상태 점검 | 0건, 오류 0건 (출시 데이터는 헤더만 제공) |
| Windows 독립 EXE·설치파일 | 수동 빌드 작업만 설정, 실제 Windows 테스트 아직 수행 안 함 |
| 실제 일본 육성 영상 프레임 | 현재 실행 환경에서는 원본 영상 파일이 제공되지 않아 직접 검수 0건 |
| 한국 서버 OCR / 자동 육성 | 범위 외, 미구현 |

### 연구 데이터의 해석

- `observed_choice` = 영상에서 플레이어가 실제로 클릭한 행동. **최적 선택이라는 의미 아님.**
- `observed_result` = 화면에서 클릭 후 결과를 확인함. 결과가 좋았는지와 다름.
- `run_purpose` = 챔미·리오히 본육성, 인자작, 평가점, 목적 미확인 중 하나.
- `review_grade=complete` = 입력 항목/프레임 증빙을 갖춘 것. **훈련 정답이나 고점 달성 보증 아님.**
- 도축은 사용자 주관이 섞인 결정이므로 목표 성능과 재시작 비용을 고려한 데이터 검증 전까지 자동 포기를 금지.

## 3. 데이터 준비의 다음 관문

실제 영상/녹화 파일 또는 허가된 화면 캡처가 확보되면, 검수 화면에서 연속된 턴을 표시하고 행동·결과를 기록한다. 이후 턴 하나하나가 아닌 **육성 기록 단위**로 학습/검증을 분리하고, 최종 실전 평가(챔미·리오히 결과)가 있는 기록을 우선 사용한다. 주관적인 제작자의 플레이 선택과 실제 결과를 서로 다른 라벨로 보관한다.

**이번 버전은 자료 수집 기반이 완성된 단계이지, 실제 대규모 영상 프레임 분석이나 ML 학습이 끝난 버전이 아니다.**

## 4. 무인도 수정 시각 출처 불일치

무인도 전용 GameWith 공략 페이지는 2025-06-30 23:20 적용으로 기재하지만 범용 패치 요약 페이지는 12:00 전후로 기재한다. R2는 상충 사실을 자료에 함께 유지하고 **패치 후 육성임을 영상별로 검수자가 명시**하게 한다.
