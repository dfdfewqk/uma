# Uma Trainer KR R13 — 일본 무인도 수정 후 4개 대회 자료팩

작성: 2026-10-15 · 배포 전 개발·연구본

## 목적

기존 R1~R12를 유지하고, 육성 **시작 전** 대회/코스/각질에 맞는 서포트 카드 6장 기본 후보, 별도 인자작 카드와 계승 고유기 후보를 보여준다. 출처가 없는 스킬의 발동률이나 승률은 계산하지 않는다.

## 확인한 2025년 일본 서버 4개 대회

| 2025-08 | 리오히 | 삿포로 잔디 2600m 우·여름·날씨·마장 랜덤 | https://gamewith.jp/uma-musume/article/show/506953 |

이는 **일본의 과거 개최 기록**이지 **한국 서버 향후 4개 개최 확정표가 아니다**. 사용자의 시나리오당 약 4개 대회 지원 요청을 위한 초기 참고 세트이다.

## 공략별 분리

- **무인도 시나리오 공통 본육성**: 스피드/스태미나/파워/근성/지능/친구 각 1장으로 구성하는 하이랜더 후보. 2025-06-30 변경 이후 기본 전략. 스킬 구성을 위해 스피드 2장 등 조정 가능. 근거 https://gamewith.jp/uma-musume/article/show/505327
- **본육성 각질 전용**: 일본 공략에서 추천한 특정 카드/스킬의 결합을 우선 고려. 실제 카드 강도·육성 승률 점수가 아님.
- **인자작 각질 전용**: 본육성에서 얻기 어려운 힌트와 녹색 스킬을 확보하도록 별도 후보 추천. 근거 https://umamusumelabo.com/chara_support/chanmi-insisupport-202507 , https://umamusumelabo.com/event/loh/loh-insisupport-202508 , https://umamusumelabo.com/chara_support/chanmi-insisupport-202509 , https://umamusumelabo.com/event/champions-meeting/insi-support-202510
- **부모마/계승**: 코스별 유효한 계승 고유기를 별도 확인. 특히 2025-09 교토 2000m 'ずっとずっと輝いて' 후보는 출처 https://umamusumelabo.com/ikusei/keisyou-202509 에서 확인.
- **검증 스탯 사례**: 2025-09 교토 2000m 선입 목표 스탯, 2025-10 니가타 1200m 추입 목표 스탯만 출처 연결. 다른 각질·대회에 무단 복제하지 않는다.

## 샘플 데이터와 모델의 차이

- 일본 공개 공략 18개 출처 URL 레지스트리, 4개 대회, 16개 각질별 프로필, 34개 본육성/인자작 카드 후보 레코드가 포함된다.
- 카드 추천은 규칙기반 **후보 선별**로 실제 스킬 발동률, 유효 발동률, 미래 경기 승률, 시뮬레이션 기반 최적화가 아니다.
- 필수 스킬 후보의 한국 표기는 일부 일본 원문으로 유지했다. 한국 서버 정식 표기, 미출시 카드 구분, 스킬 효과 수치 및 PvP 메타 최신성은 실PC/공식 자료로 재검토해야 한다.
- 카드 이름이 같은 서로 다른 타입/의상/서포트 버전이 있으므로 타입 정보를 반드시 함께 저장한다.
- 개인의 실제 보유·돌파 수·육성 캐릭터의 자체 스킬·적성·성장률·계승 상성은 아직 프로그램 자동 판독 대상이 아니다.
- 게임 클라이언트 자동 조작 기능은 아직 존재하지 않는다. 실제 게임 조작은 게임 서비스 이용 약관을 준수해야 한다.

## 파일 구조

- `research/r13/japan_island_2025_events.json`: 출처 연결된 코스·카드·스킬·계승 데이터
- `research/r13/sources.json`: 출처 ID/URL
- `plan_r13.py`: 데이터 검증 및 각질·카드 보유필터·코스 조건 선택
- `plan_ui_r13.py`: 신규 `⑭ 대회·인자` 탭 및 R12로 넘겨주기
- `tests/test_plan_r13.py`: 대회 분리, 중복, 근거, 보유카드, 인자작 구분, 출력 검증

## 수동 Windows 확인 필요

1. Python 없이 EXE/Setup가 설치·실행되는지 (Windows 빌드는 아직 확인하지 않음)
2. ⑭ 대회·인자 탭 선택→카드 보유 옵션→추천→⑬ 코스·스킬로 연결
3. 네 대회와 네 각질, 본육성/인자작별 카드 표기를 한국 클라이언트 실제 명칭과 대조
4. 2026년 한국 개최 대회 공지가 확보되면 2025 일본 기록과 혼동하지 않도록 **한국용 별도 데이터 팩** 제작
5. 내비게이션 탭 크기/스크롤, 화면 배율 100~150%에서도 표시 확인
