# R50 한국 서버 화면 보정형 자동화 — 실제 구현 범위와 현장 검증

## 1. 기준 / 구현 결과
2026-10-17 기준 main의 R49 v0.32.0을 직접 이어서 수정한다. 소스 재구축, 데이터 삭제, 이전 버전 강제 업데이트는 없다.
새 기능: R50 장면/버튼 캡처용 등록 UI, 고정 장면·버튼 두 영역 매칭, TP/스킬 숫자 OCR 2회 일치 확인, R49 자동 육성 계획/기존 전경 클릭기와 구분된 UI 입력 경로, 클릭 후 수치 변화 재확인, 종료-반복 체크포인트 저장, 클릭 중복/유료 결제 차단.

## 2. 등록 방법 (게임에서 최초 1회, 각 해당 장면당)
1. 프로그램 Companion에서 대회 통합 회차, 각질, 목표 반복 횟수를 먼저 고른다.
2. 'R50 게임 화면·TP/스킬 숫자 한 번 등록'을 열고, 실제 한국 서버 화면에서 4초 뒤 캡처 기능을 사용한다. 앱이 숨는 동안 게임 창으로 돌아가 게임을 활성화한다.
3. 등록 창에서 장면 setup/tp/skill/result/repeat 중 하나와 버튼 키를 고른다. 게임 화면 상의 고정된 장면 표식(문구/마크) 영역을 드래그하고 실제 누를 버튼 전체 영역을 별도로 드래그한다. 겹치는 영역은 거부한다.
4. 장면 키: setup=start_run, tp=start_run 또는 free_tp:verified_item, skill=skill:실제스킬이름, result=finish_run:good/ordinary/disposed/failed, repeat=repeat_run. 결과 화면은 실제 분류에 해당하는 마크여야 한다.
5. TP 아이템은 화면에서 유료 주얼과 무관한 **무료 아이템**을 직접 확인한 경우에만 무료 확인 체크를 켠다. 시각 등록만으로 아이템 수량/효과가 충분하다고 판단하지 않는다.
6. tp 장면에서 숫자 OCR 영역을 각각 등록: tp / tp_cost / tp_cap / free_item_count / free_item_recovery. 스킬 화면에서는 skill_points / skill_price. 해당 숫자들은 매 화면에서 실제 값이 두 번 연속 같을 때만 사용한다.
7. 스킬 버튼 프로필은 선택한 회차+각질에 귀속하며, 한국 서버 검증 코스가 없으면 가격을 보더라도 자동 구매하지 않는다.
8. 등록 파일은 LOCALAPPDATA/UmaTrainerKR/r50_visual_controls.json 및 r50_numeric_rois.json이다. 게임 전체 화면 대신 사용자가 선택한 장면/버튼 부분 패치만 저장한다. 기존 항목은 중복 등록 시 덮어쓰지 않는다.

## 3. 실제 자동화 범위
Companion의 '등록된 화면만 반복 자동 실행 (실험)'은 사용자가 시작 승인한 후 동작한다. R49는 훈련 5종의 OCR 상승 수치를 읽고 순회하는 잠정 선택, R50은 등록된 TP/스킬/종료/반복 버튼을 실제 게임에서 찾으면 한 번씩 클릭하는 실험이다.
단일 클릭 전에 게임 창 활성/ID/크기/전경 상태, 등록된 장면 표식·대상 버튼, 숫자 OCR 검수, R49 계획의 동일 행동 허용, 최신 프레임을 재확인한다. TP는 1개 무료 아이템 선택만 허용하며 사용 뒤 현재 TP 증가/아이템 보유량 감소가 확인되기 전까지 두 번째 클릭하지 않는다. 스킬은 Pt 감소가 확인될 때까지 재구매하지 않는다. 종료 결과를 두 번 검수한 뒤 후속 repeat 장면까지 확인해야 완료 ID를 집계한다.
사용자가 '자동 조작 즉시 중단'을 누르거나 창이 바뀌면 반복 루프까지 중지한다. 미등록/분류불가 장면에서는 자동 클릭 불가. 실제 클라이언트에 대한 통과를 아직 확인하지 않았으며 실패 시 사용자가 게임에서 직접 처리해야 한다.

## 4. 완료 기록 및 재시작 안전
R50의 별도 batch_checkpoint_r50 파일만 원자적으로 업데이트한다. 각 대회/각질/시나리오/반복 횟수, 실제 결과를 확인한 completed_ids, outcomes, 진행 중 ID/클릭 대기 상태를 보존한다. 이전 기록 축소나 결과 변경, 다른 계획 데이터 강제 병합은 금지한다. 앱이 클릭 직후 종료되거나 진행 중 세션이 남으면 자동 이어하기를 허용하지 않는다.
이 기록은 R44 기존 통계 파일을 덮어쓰지 않는다. 학습 기록과 모델 버전도 별도 관리한다.

## 5. 학습
기존 R49 outcome_learning_r49는 리뷰된 실제 한국 서버 턴 전후의 다른 증거 해시, 패치, 시나리오, run_id, turn_id 및 사용자의 실결과 확인만 기록/학습한다. train/holdout은 육성 단위 분리, 최소 검수 육성 30개와 200턴 이전에는 학습 모델을 활성화하지 않는다. 이번 단계의 미검수 OCR 수치는 그 학습 데이터로 저장하거나 정답 처리하지 않는다.
R48 잠정 훈련 점수는 스탯 합계만 반영하며, 사용자가 원한 초반 인연 1순위·우정/스킬 Pt·실패율·상위 랭커 전략의 실제 입력은 자료 검수가 부족해서 아직 반영되지 않았다. 모델 업데이트가 실전 추천에 자동 적용되는 단계도 아니다. 랭커 수준 자동 육성 완성이라고 표시하지 않는다.

## 6. 아직 실제 영상/캡처가 필요한 장면
한국 클라이언트의 TP 부족/무료 회복 상점·수량·적용 확인, 스킬 보유 Pt·각 스킬 가격/효과·구매 확인, 경기(필수/일반)/외출·이벤트 분기, 시설/섬 강화 자원, 완료 성적/최종 결과, 같은 캐릭터/덱/계승 재시작 실제 화면. R49 영상에는 훈련 화면만 있어 이 장면의 좌표를 추측해 기본 프로필로 동봉하지 않는다.
따라서 **R50은 실게임에서 즉시 20회 무중단 완전 자동화된 상태가 아니다**. 템플릿이 준비되기 전에는 등록형 실험/안전 중지까지만 가능하다. 실험 성공 후 현재 실게임 해상도, 브라우저/게임 버전, 검증된 화면 자료가 추가로 필요하다.
