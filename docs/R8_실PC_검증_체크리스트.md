# R8 Windows PC 검증 시 체크리스트

- [ ] Windows 설치 프로그램 또는 단독 EXE를 실제 Windows에서 빌드 후 실행 확인
- [ ] 기존 R7 SQLite 데이터베이스 백업 후 프로그램 실행 및 기록 보존 확인
- [ ] 한국 서버 무인도 시나리오 스크린샷으로 OCR 검증과 각 시설 레벨 실제 값 대조
- [ ] 각 시설에 우정 훈련이 발생하는 화면의 우정 인원을 실제로 확인
- [ ] 건설되지 않은 시설의 우정 훈련이 섬 트레이닝에 반영되지 않는지 화면과 대조
- [ ] 해변의 집 미건설/건설 뒤 서로 다른 시설의 복수 우정 훈련 조건 검증
- [ ] R6 실측 훈련 상승량과 R8 표시 값의 정확한 일치 확인
- [ ] 시설 건설/턴 변경 직후 기존 R7·R8 데이터가 그대로 재사용되지 않는지 확인
- [ ] 실제 시설 효과 수치/코스트/티켓 상한과 기존 일본 자료의 한국 서버 차이 확인
- [ ] 분석 JSON은 실측 데이터와 가정/정성 비교를 구분하는지 확인
- [ ] 정확한 성장 배율/우정 발생 확률의 자료가 없으면 게임 최적 성장 예측을 비활성화
