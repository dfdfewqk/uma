# UmaTrainerKR R12 개발·검증 보고서

2026-10-15 / 실험용 개발 버전 V0.12

## 목표

코스별 조건 분석과 스킬 추천을 **육성 전/스킬 구매 중** 확인. 챔피언스 미팅 및 리그 오브 히어로즈에 공통 적용.

## 구현

- 코스 프리셋 4개 + 사용자 직접 입력
- 경기장 방향, 계절, 날씨, 마장 상태, 근간/비근간 거리 조건에 맞는 녹색 스킬 자동 검토
- 검증된 코스의 종반 시작 형태(코너/직선)를 사용해 일부 실전 가속 스킬의 유효 가능성 분류
- 각질, 거리 제약 확인; 미확인 스킬은 추천을 확정하지 않음
- 사용자가 실제로 본 구매 후보/유효 Pt 입력 및 스킬별 강조 표시
- 실측 표본을 사용자에게서 입력받은 경우 발동률·유효 발동률·95% Wilson 구간·유효 빈도/Pt 지표를 분리해 표기 (사용자 입력값은 독립 검증되지 않음)
- 기존 R11 사용자 목표 스탯 5개를 표시하되 일부 출처 있는 코스에서만 스태미나 공략 예시 수치 제공
- R12 JSON 결과 내보내기, R1~R11 저장 체계 및 기존 DB 불변
- 사용자 요청에 따라 GitHub 자동 배포/커밋 없음; 수동 Windows 빌드만 준비

## 검증

`python -m unittest discover -s tests -q` → **241개 통과** (기존 R11 217 + R12 신규 24개)
