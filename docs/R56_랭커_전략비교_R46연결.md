# R56 — 조정 후 무인도 육성 판단 근거와 R46 읽기 전용 통합

## 출처별로 구분한 사실과 전략 가설
- 공식 [Cygames 시나리오](https://umamusume.jp/contents/game/scenario/designyourisland/): 6개월 건설계획·발전 Pt·섬 티켓·평가회; 공식 게임 시스템 소개이며 한국 서버의 현 패치 확인 근거는 아님.
- [GameWith 일본 서버 조정 후 공략](https://gamewith.jp/uma-musume/article/show/499493): 2025-06-30 조정 후 하이랜더 편성, 섬 훈련의 복수 우정 중요성, 티켓 수급 전 사용 필요성 및 평범한 훈련이 약한 턴의 레이스/외출 비교를 설명. 전문가/공략의 경험적 조언이며 강제 규칙·승률 수치 아님.
- [Game8](https://game8.jp/umamusume/700415): 초반 인연/우정 확보, 섬 티켓 낭비 방지, 시설 운영 설명. 연구 가설로 참고.
- [우마무스메 랩 2025-07-14](https://umamusumelabo.com/ikusei/mujintou-stepupguide): 초중반 힌트/레이스를 통한 스킬 Pt 확보도 검토하라고 설명. 단일 전략이 전 상황에서 정답이라는 의미 아님.
- [GameWith 조정 이력](https://gamewith.jp/uma-musume/article/show/270350): 2025-06-30 일본 서버 일부 시설 강화·해변의 집 복수 시설 우정 효과. KR 현 패치 수치 미검증.

## R56의 실제 구현
- R55 5개 훈련의 보상 잠정 후보를 받아 R46의 **독립 읽기 전용 연구 진단 경로**로 전달. R46 기존 검수 기반 evaluate 로직은 일체 변경하지 않음.
- 5/5 이전에는 1순위를 내지 않음. 5/5 이후 **스탯 관측 합계 1위**는 참고 정보로만 표기.
- 실패율·체력 소모·스킬 Pt 증가 모두 5종에서 확인되면 가중치를 임의로 만들지 않고, 동일 항목끼리의 파레토 비열세 후보만 계산. 우정/인연, 시설·섬·휴식·레이스가 빠졌으므로 최적 행동 확정 금지.
- 육성 단계와 티켓 만료가 실제로 확인되지 않은 경우 초반 인연 우선/섬 티켓 조기 사용 등 자동 판단을 적용하지 않음.
- 입력 소스는 OCR 검수 전 후보: game_input_allowed=False, decision_ready=False, ml_training_label=False; JP 가설은 KR 실측·학습 정답 아님.
- 랭커 영상의 실제 턴별 선택을 검수한 자료는 없으며 research/video_reviews/verified_turns.csv는 헤더만 있음. 영상이 검수된 척 정책 학습을 하지 않음.

## 다음에 필요한 자료
1. KR 게임 실제 5개 훈련 미리보기/서포트 카드 인연·우정 표시 및 각 턴 전후 결과.
2. 현재 한국 서버 공지·패치/시나리오 UI 일치 여부 검수.
3. 여러 랭커의 실제 육성 영상 속 같은 턴 선택 이유와 검증 자료 (데이터 출처/시간/영상 전후 프레임).
4. 모든 행동(훈련·레이스·외출·휴식·섬 훈련·시설)의 리소스·결과를 확인한 후 R46 verified path로 승격.
