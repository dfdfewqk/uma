# R58 — 영상 수집 이전에 가능한 육성 시작 전 사전 점검

기준 커밋: `acd881a91e2a2ac19fdfafdd8b8257780088739d` (R57). 기존 R51 백업 브랜치, 정상 동작 및 사용자 로컬 설정은 그대로 유지.

## 확인된 문제
- R57 시점 반복 자동 실행 진입은 TP/결과/반복 **장면 유형**과 TP OCR 5종 등록 여부만 검사한다.
- `setup:start_run`과 `tp:start_run` 버튼 존재 여부를 엄밀히 검사하지 않았다. 동일 장면의 다른 버튼만 등록해도 진입 준비로 오해할 수 있다.
- 시작 확인 문구에서 캐릭터·서포트 카드 덱·계승·각질을 사용자 확인에 맡기는 한계가 명확하게 드러나야 한다.

## 이번 작은 개선
- `setup_preflight_r58.py`: 순수 읽기 전용 등록 점검. `setup:start_run`, `tp:start_run`, `result:finish_run:*`, `repeat:repeat_run` 검수 등록과 TP 숫자 영역 `tp, tp_cost, tp_cap, free_item_count, free_item_recovery`를 검사한다.
- 무료로 검수되지 않은 `free_tp:*` 등록도 사전 점검에서 거부한다.
- 도우미에 **R58 육성 시작 준비 점검 (클릭 없음)** 버튼 추가. 부족한 등록 항목을 출력할 뿐 실제 게임에는 입력하지 않는다.
- 반복 실험 자동 실행 시작 시 같은 사전 점검을 필수로 수행한다. 이후 별도 확인창에서 캐릭터·덱·계승·각질의 **사용자 직접 확인**을 요구한다.
- 등록 프로필과 스크린샷은 실제 구성 일치의 증거가 아니다. setup 장면에서 자동으로 캐릭터/카드/계승을 선택하거나 진행한다는 의미도 아니다.
- 기존 R50 스킬·TP 구매 로직/클릭기와 R57 후속 화면 검증을 수정하지 않는다. 유료 결제·미등록 장면 자동 입력 금지 유지.

## 검증 결과
- 새 `tests/test_setup_preflight_r58.py` 사전 점검 모듈 합성 테스트 5개 **로컬 통과** 및 두 파일 Python 구문 검사 통과.
- 저장소 전체 통합 회귀테스트, Windows GUI/EXE 빌드, 실제 KR 게임 테스트 **미실시**.
- 영상이 도착하면 setup 화면에서 실제 캐릭터/서포트 구성/계승 장면과 진행 버튼 위치를 검수해 후속 구현 가능.
