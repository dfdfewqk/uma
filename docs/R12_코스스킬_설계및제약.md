# R12 — 코스별 목표 및 스킬 구매 보조 (2026-10-15)

## 목적

- **육성 시작 전:** 코스 선택 → 방향/거리/계절/날씨/마장 상태/각질을 검토 → 근거 출처를 가진 녹색 스킬과 일부 핵심 가속/속도 스킬의 적합성 확인.
- **육성 중:** 화면에 실제로 보이는 스킬을 `스킬명 | 유효 Pt | 상태 | 경기수 | 발동수 | 유효발동수` 형식으로 입력하고 적합성을 구분해서 표시.
- **챔미와 리오히:** 같은 코스라도 육성 목적은 프로필로 분리하되, 정확한 대회 메타/유저 확보 가능한 스킬을 검증하지 않고 임의로 설정하지 않음.

## 신뢰도 구분

1. 녹색 스킬 조건은 `시계/반시계, 400m 근간거리, 경기장, 계절, 날씨, 마장 상태`의 명시적 조건 일치/불일치/미확인만 계산한다. 경주 승률과 동일시하지 않는다.
2. 가속기는 종반 진입 시점(코너/직선)과 각질을 확인한 **후보**만 표시한다. 순위·기수·다른 스킬 발동·각질 분포 등은 모르면 발동 확률을 계산하지 않는다.
3. 표에 표시되는 발동률은 사용자가 직접 입력한 `발동수/경기수`, 유효 발동률은 `유효발동수/경기수`이다. 프로그램이 자동 검수한 실측 자료는 아니며 **ML 학습에 포함되지 않는다.** 95% Wilson 범위는 입력 표본의 통계적 불확실성만 표시하며 다음 경기의 발동 확률을 보장하지 않는다.
4. `유효 관측 빈도 / 100Pt`는 비용 비교용 단순 지표다. 스킬 속도/가속 효과 크기, 지속시간, 스탯 보정, 획득에 필요한 인자작 비용을 반영하지 않으므로 실제 가성비와 동일하지 않다.
5. 스탯 5종은 기존 사용자 목표를 모두 보여준다. 사이트 공략에 수치가 명확한 예시인 스태미나만 출처를 표시하며 **다른 스탯을 확정 권장치로 만들지 않는다.** 캐릭터/각질/회복/코스 보정에 따라 바뀔 수 있다.
6. 일본 공개 자료와 한국 서버에 존재하는 스킬·진화스킬의 시점은 다를 수 있다. 프로그램의 미리보기는 *획득 가능한 스킬 목록*이 아니고, 실제 구매 가능 여부는 유저가 게임 화면에서 확인하도록 한다.

## 실제 게임에서 필요한 다음 테스트

- 한국 서버에 존재하는 스킬명과 현재 적용 밸런스 확인
- 스킬 OCR과 힌트 할인 Pt 확인 (R12는 수동 입력 방식)
- 한국 서버 4개 코스의 종반 시작 위치·스킬 발동 시점 검증
- 실제 인게임 가속기 발동 영상/경기 로그 수집, 관측 표본 품질 검사
- 스킬 효과 크기·지속시간·발동 타이밍을 포함한 실전 효용 공식 또는 시뮬레이션 검증
- Windows EXE/설치파일 빌드·실행, DPI와 다양한 모니터 크기 테스트

## 보존/배포

R1~R11 원본·저장 구조 유지. Windows 빌드는 workflow_dispatch로만 실행되며 공개 Release는 별도 opt-in. 인터넷이 필요 없는 구조. 이번 개발에서는 저장소 커밋·자동 배포하지 않음.
