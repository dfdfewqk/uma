# R38 — 턴별 필수 목표 레이스·터커 브라인 외출 판단의 근거 기반 설계

작성: 2026-10-16 / 연구 전용, **R37 Windows EXE에 자동 포함되는 UI 기능이 아님**.

## 반드시 구분할 일정

1. **챔미·리오히 대회 개최일**: R13이 정리한 일본 2025년 대회 4건. 육성 도중 어떤 턴에 출전해야 하는 레이스인지 나타내지 않는다.
2. **게임 내 레이스 전체 캘린더**: 주니어·클래식·시니어 각 월 전/후반의 일반 레이스. 레이스 종류/출전 가능성은 캐릭터 적성·팬 수·목표 충돌을 따져야 한다.
3. **현재 육성 캐릭터의 고유 목표 목록**: 캐릭터 및 의상/육성 목표 차이에 따라 달라진다. 무인도는 캐릭터 고유 목표를 사용한다. 반드시 현재 캐릭터와 목표 화면에 대조해야 한다.
4. **무인도 고유 일정**: 시설 건설, 섬 티켓, 평가회, 여름 합숙, 서포트 이벤트 등. 목표 레이스가 겹치면 다음 턴 버프의 가치가 달라진다.

R38의 `RaceGoal`, `CharacterCalendar`, `ScreenTurn`은 이를 혼동하지 않도록 분리했다. 캐릭터/의상·서버·패치 불일치, 목표 화면 미확인, 달력 미완성에는 자동 목표 레이스 추천을 만들지 않는다. **전체 캐릭터 목표 달력은 아직 수집·검수하지 않았으며 현재 0개**다.

목표 정보 확인을 위한 외부 참고: GameTora의 [Race Scheduler](https://gametora.com/umamusume/race-scheduler), 일본 공략의 캐릭터별 목표. **자료를 자동으로 복제·확정한 것은 아니다.**

## 고정 친구 카드 가설: SSR 터커 브라인

정확한 한국 이름·채용 카드는 실제 덱 화면과 일치시켜야 한다. 무인도에서는 일본 자료 기준 SSR タッカーブライン이 유력하다. 외출을 **1회차~5회차 별개의 행동**으로 계산하고, 해금 여부·카드 돌파·현재 단계가 화면에서 확인되지 않으면 숫자를 확정하지 않는다.

일본 서버 2025년 6월 30일 이후 참고값, **SSR 4돌파 + 무인도 시나리오 보정**:

| 외출 차례 | 일본 공략 기준 회복 | 다음 턴 특기율 상승 후보 | 주의 |
|---|---:|---:|---|
| 1회 | +32 | +20 | 최대 체력 증가, 스태미나 상승(일본 출처 간 스탯 충돌 있음) |
| 2회 | +32 | +20 | 스피드 상승/힌트(일본 출처 차이 있음) |
| 3회 | 회복 선택 +80 / 스탯 선택 +0 | +30 | 유저가 게임 안의 선택지를 직접 클릭. 두 선택을 하나로 취급 금지 |
| 4회 | +40 | +20 | 스태미나/근성 상승 |
| 5회 | +48 | +120 | 파워/스킬 힌트, 다음 턴 효과 강하지만 목표 레이스와 충돌 가능 |

회복량은 다른 돌파 등급에서 20~32, 3회 50~80, 4회 25~40, 5회 30~48 등으로 달라질 수 있다. 수치는 **현재 게임에서 실제로 회복한 수치가 아니다**. 확인한 체력 상한을 초과한 회복량은 효용 계산에서 제외하고, 실제 캐릭터의 체력 최대치를 임의로 100으로 고정하지 않는다.

**출처 충돌**: 일본 Game8의 첫 두 외출 보너스 스탯 배치는 GameWith·ウマ娘ラボ와 뒤바뀌어 기록되어 있다. R38 자료팩은 일치하는 회복 숫자만 기준값으로 기록하고 스탯 표기는 충돌 사실을 남겼다. 인게임 확인 이전에 부가 스탯을 확정 공식으로 사용하지 않는다.

## 매 턴 자동 판단에 실제 필요한 화면 정보

- 현재 육성 캐릭터·의상, 현재 연도/월/전후반, 다음 목표 레이스의 이름/시점/남은 턴
- 모든 훈련에서 실제 상승·체력 소모·실패율·우정 위치·섬 훈련 티켓/보유/만료 상태
- 현재 체력·체력 상한·컨디션, 휴식 화면에 보이는 회복량/휴식 특수 효과
- 터커 브라인 지원 여부·돌파·외출 해금·다음 외출 단계, 별도 보상 선택지(발전 Pt/스킬 Pt)
- 레이스 출전이 필수인지 선택인지, 1턴 뒤 버프가 훈련에 사용 가능한지

## 결정 순서(오입력/사전 지식 추측 금지)

1. 창/장면/게임 턴 식별 불명확 → 이전 결과 폐기, 추천 보류.
2. **실제 게임 목표 화면에서 이번 턴 필수 목표 레이스가 확인** → 목표 레이스 우선 안내.
3. 다음 턴 강제 레이스 → 친구 외출·터커 동반 훈련의 다음 턴 특기율 보상 소비 위험 확인.
4. 체력이 낮아 훈련 효율이 불리하면 **일반 휴식 vs 터커 외출 현재 회차**의 실제 회복량과 초과 회복, 외출 이후 효과, 남은 외출/턴을 비교. 낮은 체력 숫자 한 번만으로 휴식을 확정하지 않음.
5. 훈련이 좋고 회복 비용보다 기대 성장과 인연 확보가 크면 훈련 우선 검토. 섬 티켓 만료/다음 수령/3곳 이상 우정 후보와 발전 Pt를 함께 검토.
6. 모든 행동의 화면별 수치가 아직 부족하면 비교 불완전으로 표시. **미확인 수치를 자동 타이핑으로 대체하지 않는다.**

## 구현 및 검증 상태

- `race_outing_r38.py`: 캐릭터별 목표 달력 범위 검증, 목표와 현재 턴 간 거리, 친구 외출 단계·회복 참고값 안내, 정보 부족 시 보류.
- `research/r38_tucker_outings_jp.json`: 출처·가정·충돌·제약을 포함한 일본 4돌파 외출 단계 자료.
- `tests/test_race_outing_r38.py`: **합성 데이터 15개 회귀 케이스 작성**. Python/Windows 실제 실행 통과는 아직 미확인.
- **이 코드는 현재 자동 화면 인식·Companion 추천 버튼에 연결되지 않았다**. 차기에는 KR 게임 UI에서 현재 캐릭터·턴·외출 단계 검출을 먼저 검증해야 연결할 수 있다.
- 신뢰할 수 있는 외부 데이터가 없어 캐릭터별 목표 레이스를 임의 생성하거나, 친구 카드가 고정이라고 모든 덱에 적용하지 않는다.
- 게임 자동 클릭/키 입력, ML 가중치 변경, 기존 R6 점수/사용자 데이터/저장소 스키마 변경 없음.
