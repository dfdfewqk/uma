# Uma Trainer KR V0.8 R8 — 구현 및 검증 결과

## 목표

일본 서버 2025-06-30 밸런스 조정 이후 무인도 규칙에 근거해, 기존 R7 시설 건설 계획의 **시설 적용 조건**과 기존 R6에서 검수된 **이번 턴 섬 트레이닝 수치**를 통합합니다. 근거가 없는 시설별 성장 배율은 임의로 생성하지 않습니다.

## 실제 반영

- ⑨ R8 화면 추가. R7/R6 및 기존 데이터베이스 구조 유지.
- 스피드·스태미나·파워·근성·지능의 이번 턴 우정 훈련 인원을 5개 모두 확인해야 비교합니다. '미확인'을 0으로 취급하지 않습니다.
- 섬 훈련 적용 우정: **우정 발생 + 해당 시설 건설** 모두 충족한 시설만 포함합니다. 인원수와 발생 시설 수를 분리합니다.
- 해변의 집 Lv1 이상이고 **서로 다른 건설된 시설 2개 이상에서 우정**이 있으면 수정 후 '복수 시설 우정 효과'의 적용 조건에 해당하는 것으로 표기합니다. 이 조건이 곧 정확한 보너스 배율이나 추가 스탯을 뜻하지는 않습니다.
- R7 각 후보의 건설 단계별 적용 가능/미건설 제외 시설 차이를 구조적으로 비교합니다. 이때 미래 우정 배치를 예측하지 않고 **현재 같은 배치가 계속 발생한다고 가정**합니다.
- R6의 검수 당시 프로필·턴·선택지 해시가 일치할 때만 현재 턴 섬 트레이닝의 사용자가 입력해 확인한 상승량과 실험 점수를 연결합니다. R6 전체 검수 불완료 또는 변경된 선택지는 연결하지 않습니다.
- 구조 분석 JSON은 기존 SQLite를 수정하지 않고 별도 파일에 원자적으로 저장합니다. 출처·검증상태 `experimental_only=true`, `ml_training_label_verified=false`, `verified_optimal=false`를 포함합니다.
- 새 육성·새 턴에 기존 검수 데이터를 자동 재사용하지 않고, 저장 전 컨텍스트 해시를 재확인합니다.
- 시설 공식 효과의 정확한 스탯 가산, 미래 우정 발생 확률, 시나리오 최적화/승률/ML은 **미구현**입니다.

- [GameWith 무인도 시나리오](https://gamewith.jp/uma-musume/article/show/499493) — 6/30 조정 후 시설 효과 및 하이랜더 편성
- [4Gamer 무인도 사전 플레이](https://document.4gamer.net/games/414/G041434/20250610058/) — 미건설 시설의 우정 훈련 적용 제외 설명

참고: 일부 자료는 출시 직전의 구조 설명 또는 조정 후 공략입니다. 한국 서버 실제 화면 확인 시 차이를 재검증해야 합니다.

## 시험 범위

- 기존 R1~R7 자동 테스트 유지 + R8 신규 테스트 추가.
- Linux 가상 디스플레이(Xvfb)에서 실제 Tkinter 앱 실행, 10개 탭 확인, R7 임시 건설 경로/ R8 검수/ 화면 캡처 확인.
- 합성·가상 데이터만 사용. 실제 일본/한국 서버 플레이 영상 턴 데이터 검증 **0건**, 한국 서버 실제 OCR **0건**, ML 학습 **미진행**.
- Windows EXE / Setup.exe 생성 및 설치 테스트는 아직 수행하지 않음. GitHub Actions는 수동 빌드 설정만 유지하며 자동 커밋·자동 배포하지 않음.
