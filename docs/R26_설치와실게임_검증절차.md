# R26 — 설치 패키지와 실게임 첫 검증

## 배포 전제

이 문서는 개발자용 소스 ZIP과 사용자가 실제 실행하는 **Windows 설치형 EXE**를 구별합니다. 본 R26 소스에는 Windows에서 수동 빌드하는 GitHub Actions만 포함됩니다. 연결된 GitHub 계정에 Uma Trainer KR 전용 저장소가 아직 확인되지 않았으므로, 다른 프로젝트에 임의 커밋하거나 워크플로를 실행하지 않았습니다.

## 수동 빌드와 검증

1. 전용 저장소를 만들고 이 소스의 루트 내용을 업로드합니다. 기존 `.github/workflows/windows-exe.yml`를 반드시 포함합니다.
2. Actions에서 `Build and verify Windows installer (manual only)` 실행. 자동 `push`, 자동 `release`는 활성화하지 않습니다.
3. 452개 소스 테스트 및 컴파일 검사(현재 Linux 환경 확인 수치)를 Windows에서도 다시 수행합니다. 수치는 향후 테스트 추가에 따라 바뀔 수 있습니다.
4. PyInstaller로 4개 EXE를 구성합니다. 각 EXE를 `--self-check-report`로 **실제 실행**하여 필요한 내부 리소스가 있는지 확인합니다.
5. 도우미 EXE를 `--first-run-report`로 실행해 환경 진단 코드가 동작하는지 확인합니다. Windows 러너에는 우마무스메가 설치되지 않았을 수 있으므로 게임 미탐지는 정상입니다.
6. Inno Setup으로 `UmaTrainerKR_Setup_0.26.0.exe`를 생성하고 자동 설치합니다.
7. 설치된 4개 EXE의 SHA-256을 빌드된 4개와 비교하고, 설치된 파일에서 자체 검사 및 첫 실행 진단을 수행합니다.
8. 자동 제거 후 4개 EXE 파일이 제거됐는지 점검합니다. 실제 사용자 `%LOCALAPPDATA%\UmaTrainerKR` 기록은 삭제하지 않습니다.
9. **성공한 경우에만** `UmaTrainerKR-R26-Windows-Verified`라는 GitHub Actions 다운로드 가능한 아티팩트를 생성합니다. GitHub Release 게시는 하지 않습니다.

## 게임 실행 후 사용자 검증

1. Windows 설치형 EXE에서 **작은 도우미**가 정상 실행되고 게임 창을 탐지하는지 확인.
2. 게임 화면 종류(훈련/스킬/시설) 변경 시 이전 OCR·추천 표시가 사라지는지 확인.
3. 무인도 시나리오의 훈련 5개를 **각각** 선택하여 상승량·실패율·스킬 Pt를 읽고, 눈으로 맞는지 검수.
4. 위치 감지가 중복되거나 미확인되면 추천을 보류하는지 확인.
5. 스킬 목록을 스크롤했을 때 이전 스킬 강조가 남지 않는지 확인.
6. 도우미 위 다른 앱이 올라와 있는 상태와 게임이 비활성화된 상태에서 잘못된 게임 정보 인식이 없는지 확인.

## 상태 구분

| 진단 코드 | 의미 |
|---|---|
| `ENVIRONMENT_INCOMPLETE` | Windows, 화면 캡처 또는 이미지 비교 모듈 미준비 |
| `OCR_NOT_CONFIGURED` | Tesseract OCR 확인 필요 |
| `GAME_NOT_DETECTED` | 실행 중인 우마무스메 게임 창을 찾지 못함 |
| `CALIBRATION_REQUIRED` | 숫자/장면/훈련 버튼 기준 등록이 덜 됨 |
| `READY_FOR_GAME_VALIDATION` | 기본 준비 완료. **실제 게임 정확도 검증은 아직 필요** |

`--first-run-report`는 스크린샷·창 제목·사용자 이름·게임 기록을 저장하지 않습니다. 저장하려는 JSON 파일이 이미 있으면 덮어쓰지 않고 종료합니다.

## 확인되지 않은 항목

- Windows CI 빌드 **실행 자체** (아직 아티팩트 없음)
- 배포판의 실제 Tesseract OCR 설치 여부
- 우마무스메 한국 서버의 훈련/스킬 화면 인식 정확도
- 게임 화면 위 추천 표식의 Windows 환경 클릭 통과 여부
- 자동 클릭/자동 육성 (미구현)
- 사용자가 나중에 게임 업데이트를 마친 뒤 실측 검증한 결과

다음 R27은 실제 Windows 빌드 로그/화면 캡처로 발생한 오류를 우선 수정합니다. 배포 가능하다는 판단은 게임 호환 검증과 별개입니다.
