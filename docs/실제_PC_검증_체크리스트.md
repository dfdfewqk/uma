# 우마무스메 한국 서버 PC 분석기 V0.2 — 실기 검증 체크리스트

**현재 상황:** Python 수동 입력 분석기와 Windows EXE/설치파일 생성 설정을 준비했습니다. 테스트용 가상 값을 이용해 엔진·GUI·SQLite 저장은 확인했으나 **한국 서버 게임 직접 인식·Windows 자체 EXE·설치파일은 아직 실기 검증하지 않았습니다.**

## A. 설치파일을 처음 검증하는 날 (10~15분)

- [ ] GitHub에 코드를 **한 번에** 반영한다. 저장소 기존 원본을 덮어쓰지 않도록 전용 브랜치 또는 저장소를 사용한다.
- [ ] Actions → `Build Windows EXE + Installer (manual only)` → Run workflow, `publish_release=false`로 실행한다.
- [ ] 테스트와 빌드가 모두 성공해야 아티팩트(`UmaTrainerKR.exe`, `UmaTrainerKR_Setup_0.2.0.exe`)가 생성된다.
- [ ] Windows Defender/SmartScreen 경고가 있다면 이유를 먼저 확인한다. 서명되지 않은 새 실행파일은 경고가 날 수 있다.
- [ ] 설치형과 단일 EXE 중 최소 하나를 테스트 PC에서 실행한다.
- [ ] V0.1을 이미 사용한 PC에서는 기존 육성 기록이 자동 보존되는지 확인한다. 업데이트 전 SQLite와 `screenshots/`을 별도로 백업한다.

## B. 게임 없이도 확인 가능한 기능 (5분)

- [ ] 무인도 시나리오 / 챔미·리오히 전환이 가능하다.
- [ ] 가상 예제 불러오기 → 추천 계산 → 행동 근거 설명이 나온다.
- [ ] 값이 없는 선택지는 추천 순위에서 제외된다.
- [ ] 티켓 0개인 섬 트레이닝은 추천되지 않는다.
- [ ] 새 육성 시작 → 실제 선택 기록 저장 → 목록에서 이어쓰기 동작을 확인한다.
- [ ] 결과 상태를 `육성 완료` 또는 `도축/중단`으로 저장할 수 있다.
- [ ] SQLite 백업, CSV, JSON, 연구용 CSV 내보내기를 확인한다.

## C. 실제 게임을 켤 수 있을 때 (필수)

- [ ] 한국 서버 무인도에서 1366x768 / 1920x1080 등 대표 화면 크기의 스크린샷을 수집한다.
- [ ] 게임 안에 실제로 표시되는 훈련 보상·우정 인원·시설 단계·티켓·발전 Pt를 직접 확인한다.
- [ ] 일본 2025-06-30 패치 후와 한국 버전의 시설/훈련 수치가 일치하는지 검증한다.
- [ ] 5턴 이상의 수동 입력 기록을 비교해 명백한 오류가 없는지 살핀다.
- [ ] 현재 가중치가 **검증되지 않은 가정**임을 유지하고, 실측 결과에 맞춰 보정한다.

## D. 공개 배포 전 통과 조건

1. 새 Windows 컴퓨터에 Python 없이 설치하고 실행 가능
2. 여러 번 종료·재실행해도 이전 기록과 스크린샷 유지
3. 오류 발생 시 `%LOCALAPPDATA%\UmaTrainerKR\last_crash.log` 분석
4. 실제 한국 서버 값과 계산기 입력 규칙 검증
5. 검증 실패 시 GitHub Release 공개 금지 (`publish_release=false` 유지)
