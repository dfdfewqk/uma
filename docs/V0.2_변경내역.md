# V0.2 변경사항 — V0.1을 기반으로 확장

1. **시나리오 정책 분리:** 무인도 정책을 전용 모듈과 데이터 JSON으로 옮겨 다른 시나리오의 신규 엔진 추가 기반 제공
2. **미입력 행동 오류 방지:** 확인하지 않은 훈련은 추천에서 제외; 상승량이 실제로 0인 행동은 명시적으로 확인 표시
3. **불가능한 행동 제외:** 섬 티켓이 없거나 체력이 부족한 행동은 추천 후보에서 제외
4. **대회별 위험 성향 초안:** 리오히 실패 위험을 더 보수적으로 보는 실험용 가중치 (검증 전)
5. **조건 기록:** 경기장/마장/방향/환경, 편성·계승 메모 추가
6. **도축·완주 결과 저장:** 상태, 중단 이유, 최종 스탯·성과 메모 기록
7. **SQLite 스키마 이전:** V0.1 기존 데이터 보존, 결과 컬럼만 추가
8. **데이터 손실 대비:** SQLite 온라인 백업, CSV/JSON 내보내기 유지
9. **연구용 CSV:** 실제 선택이 기록된 턴만 추출 (선택이 유효했다고 보장하지 않음)
10. **검증:** 핵심 자동 테스트 18개, 가상 데이터 이용한 Tkinter UI 저장 플로우 점검

미완료: 실제 Windows EXE 빌드 검증, 한국 서버 화면 OCR, 자동 게임 진행, 확률 보정, ML 학습, 대규모 육성 영상 턴별 수집.
