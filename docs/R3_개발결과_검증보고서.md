# Uma Trainer KR R3 — 육성 자료 품질 감사와 목표 부담 분석

## 범위

기존 **V0.2+R1+R2 자료 및 기능을 보존**하고, 일회성 학습 완료 주장 대신 사용자가 기록한 육성 자료의 증거 품질을 판별할 수 있는 R3를 추가했다.

- `analytics_r3.py`: 로컬 SQLite 세션의 관측 데이터 감사와 통계 요약
- `app.py`: **④ R3 데이터 검증** 탭, 세션 분석 / 전체 연구 자료 감사 / JSON / 검증 후보 CSV 내보내기
- `tests/test_analytics_r3.py`: 신규 자료 부족, 관측 일치율, 연속 턴 구간 필터, 변경된 프레임 해시, 출처 위조 및 목적 오분류 검사
- `research/video_reviews/R3_audit_현황.json`: 실제 연구팩의 현 상태 요약(영상 검증 턴 0개)

## 해석 주의

1. **추천-실제 선택 일치율**은 실험용 규칙 엔진과 사람이 같은 선택을 했다는 지표다. 정확도/승률 또는 사람의 선택이 정답이라는 의미가 아니다.
2. **연속 턴의 스탯 차이**는 앞 턴 상태와 다음 턴 상태의 변화로, 사이에 발생한 이벤트나 선택까지 포괄한다. 훈련 행동의 순수 인과 효과가 아니다.
3. 기록된 연속 턴이 5쌍 미만이면 '과거 상승 분포'를 제시하지 않으며 **도축 판단을 보류**한다.
4. 5쌍 이상이어도 도축 추천은 하지 않는다. 목표 대비 부담만 경고하고 사용자 판단을 남긴다.
5. **일본 수정 후**는 연구자료의 출처·날짜·패치 근거로 필터링한다. 한국 서버 동일 수치는 아직 검증되지 않았다.
6. 영상 연구 행을 학습 후보로 추출하려면 챔미/리오히 본육성, 기등록된 영상 출처, 수정 후 패치 근거, 선택 전후 프레임 원본의 SHA256 무결성, 2개 이상 비교 후보, 스탯/체력, 실제 선택/결과 등 필수 필드가 있어야 한다.
7. 완전 검수 행도 인간 행동을 그대로 최적 행동 정답이라고 간주하지 않는다. **ML은 학습하지 않았다.**

## 보존 및 데이터 관리

데이터 저장 경로는 기존 V0.2와 동일하게 `%LOCALAPPDATA%/UmaTrainerKR/runs.sqlite3`. 데이터베이스 컬럼 변경 없이 읽기 전용 분석/내보내기만 추가하므로 기존 기록을 삭제하지 않는다. 연구 영상/저작권 파일은 ZIP에 포함하지 않는다.
