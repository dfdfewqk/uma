## 이번에 구현한 구조적 방어

1. `validate_research.py`에서 검수 턴이 1개라도 존재하면 무조건 실패하던 제한을 제거했다. 대신 검수 상태, JP 패치 태그, 출처/케이스 연결, 원본 프레임 전후 해시, 행동 후보/선택, 범위를 **형식 차원에서** 검증한다.
2. 현재 `turn_annotations.csv`는 헤더만 존재하며, 해당 자료의 실제 관측 수는 0이다.
3. 빈 문자열·잘못된 JSON·타 서버/패치 혼입·선택지 밖 행동·검수 미확인·동일 전후 이미지 해시는 거절한다.
4. `manifest.json`의 출처/관측 개수와 파일의 실제 행 수가 일치해야 한다. 자료를 임의로 학습 가능하다고 승격할 수 없다.
5. 합성 테스트는 `tests/test_research_r32.py`에만 존재한다. 연구 CSV와 실제 학습용 파일에는 가짜 데이터나 추정 숫자를 넣지 않았다.

## 실행 및 남은 문제

- 출처/참조 검증: `python research/jp_post_patch_2025/validate_research.py`
- 합성 형식 검증: `python -m unittest discover -s tests -p test_research_r32.py -v`
- 전체 테스트: `python -m unittest discover -s tests -q`

이 감사는 실제 영상이나 게임 플레이를 확인하지 않는다. SHA-256·검수 메타데이터는 진위를 보증하지 않는다. 따라서 R15 이미지 원본 검수, 출처 그룹 중복 검사, 패치별 구분, R16 홀드아웃 검증 전에는 학습/자동 추천 점수 교체 금지.

## 게임 접근 가능해진 뒤 수집할 최소 자료

- 훈련, 스킬, 시설, 이벤트의 대표 화면 (화면 크기, 입력창/버튼 판별 포함).

- 챔미/LoH, 거리/각질, 지원 카드 구성과 패치/시나리오 버전을 함께 기록한다. 모든 화면은 한국 서버 자료로 별도 보관하고 JP 2025 자료와 합치지 않는다.
