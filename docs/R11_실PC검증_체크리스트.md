# R11 Windows PC 검증 체크리스트

- [ ] 기존 사용자 V0.10 DB 백업을 만든 뒤 V0.11에서 그대로 열리는지 확인 (데이터 삭제 금지)
- [ ] 배포용 EXE와 Setup.exe가 Python 미설치 Windows에서 기동하는지 확인
- [ ] ⑫ R11 탭이 창 크기 1040×720에서 접근 가능한지 확인
- [ ] 무인도 시나리오 / 챔미·리오히 이외 육성 목표 거부 확인
- [ ] 실제 필수 스킬 목록, 획득 여부 및 할인된 **현재 구매 비용** 수동 입력 후 계산 일치 확인
- [ ] 스킬 비용 미확인 시 '계산 보류' 유지 확인
- [ ] 시설 레벨 6종과 향후 목표 Lv를 기록하고 빈 목표가 0레벨로 처리되지 않는지 확인
- [ ] 평가회 목표 발전 Pt 및 남은 턴의 산술 부족량 검수
- [ ] 다음 섬 티켓 지급 시점 미확인 시 사용 최적 시점 추천하지 않는지 확인
- [ ] 새 턴, 새 육성 시작, 입력 변경 시 저장했던 R11 결과가 재사용되지 않는지 확인
- [ ] JSON 내보내기에 개인 스크린샷 경로가 포함되지 않는지 확인
- [ ] 실제 게임 원본 녹화 없이 임의 수치로 만든 데이터가 R9 공식 검증 표본에 혼합되지 않는지 확인
- [ ] 챔미/리오히 실제 경기 조건에 적합한 스탯·스킬 목표인지 별도로 확인

**주의:** R11은 목표 격차 도구이며 승률 예측기 또는 학습된 ML 모델이 아닙니다.
