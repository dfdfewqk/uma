# R59 — 한국 서버 육성 시작 전 선택지 확장 기반 (영상 검증 전)

- 기준 R58: `803c247b24632e605903d0dbd631e6443b41acab`. 기존 등록 파일 R20/R50/R53/R54 및 사용자 게임 데이터 불변.
- 사용자 요청: 보통 시작 방식과 기능 시험 이벤트의 시작 화면은 다를 수 있다. **영상에 나타난 실제 버튼·순서만 추후 확정**하고, 미확인 단계는 임의 클릭하지 않는다.
- 사용자 제공 영상 3개 `Video1.mp4`, `Video1 (1).mp4`, `Video Project 6.mp4` 및 YouTube 영상 `E19uBCIOjic`을 이번 단계에서 확인하려 했지만, 첨부 동영상을 처리하는 Python/컨테이너 실행 환경이 ClientError를 반복 반환하고 YouTube 페이지 내용도 가져오지 못했다. 따라서 **실제 영상 장면 분석 완료라고 주장하지 않는다**.
- 영상 자료 분석과 무관하게 준비할 수 있는 기반만 먼저 추가.

## 구현
1. 신규 사용자 등록 도구에서 `normal`(평소 육성)과 `event`(특별 이벤트) 경로를 구분해 시작 전 선택지의 *단계명·선택지명*을 사용자가 등록할 수 있다.
2. 고유 화면 표식과 선택 버튼을 서로 다른 영역으로 등록한다. 게임이 활성화된 경우에만 4초 지연 캡처, 소리 분석 불필요.
3. 실제 화면에 표시된 선택지를 두 프레임 연속 인식해야 화면 옆에 후보로 표시한다. 두 가지 경로나 단계가 동시에 일치하면 선택을 보류한다.
4. `r59_setup_choices.json`에 따로 보존하며 덮어쓰기·링크 입력을 거부한다. R50 기존 자동 클릭 프로필과 섞지 않는다.
5. R59은 **보이는 선택지 표시만** 구현한다. 게임에서 어떤 선택지를 누를지, 그 다음 단계가 무엇인지, 선택 버튼 클릭 좌표는 영상 검증 전 미확정이다. 클릭 위치를 자동 추측하거나 화면이 일치한다는 이유만으로 권한을 부여하지 않는다.
6. 사용자 요청에 따라 이번 작업에서 육성 실패/포기 이유, 후반 훈련, 오디오 분석은 진행하지 않는다.

## 검증 한계
- 테스트 파일: `tests/test_setup_choices_r59.py` — 독립 화면 특징 일치, 경로/단계 모호성, 2프레임, 창 변경, 기존 설정 보존, GUI 연결을 테스트하도록 작성.
- 현재 Python·컨테이너 실행 환경 오류로 이번 테스트 자체는 실제 실행 검증하지 못함.
- 실게임 UI 및 Windows 실행파일/자동 입력의 테스트도 미실시. 배포·빌드 없음.

## 영상 판독 가능 시 필요한 후속 작업
- 각 영상의 **시작 전 장면 프레임만** 시간순으로 분리해 기본/이벤트 분기를 실제로 확정한다.
- 현재 한국 서버와 평상시 YouTube 육성 시작 단계별 버튼·스크린 좌표를 교차 검증한다.
- 그 다음에만 게임 상태 전이 검증 및 승인된 선택 행동을 연결한다.
