# Uma Trainer KR R6 — 기능·검증 보고서

- 버전: 0.6.0 (2026-10-15)
- 개발 기준: 기존 V0.5 R5 소스/연구자료 유지, R6만 점진적으로 추가
- 데이터 원칙: 일본 서버 2025-06-30 무인도 밸런스 조정 이후를 참고하되 공식 계산식/한국 서버 수치로 간주하지 않음

## 변경 사항

- `decision_r6.py`: 5종 일반 훈련 + 섬 훈련(티켓 있을 때) + 휴식 + 외출 + 레이스의 **전 행동 검수 게이트** 및 실험 점수 비교.
- 모든 행동에 대해 `가능` / `불가` / `미확인`을 구분. 미확인 가능성이 있으면 전체 추천 보류.
- `가능`인 행동에는 사용자가 직접 수치 확인(`observed=True`)을 한 데이터가 있어야 함.
- 체력 회복 상한 100을 초과하는 기대 회복량은 점수 계산에서 잘라냄.
- 남은 턴이 많고 인연도 상승 효과가 있으면 소량의 실험 가중치 반영. 행동 후 체력이 매우 낮으면 다음 턴 부담을 추가 반영.
- 리오히 훈련 실패 위험은 공통 엔진의 보수적 계수를 사용. 임의의 승률은 계산하지 않음.
- 무인도 티켓 0이면 섬 훈련 불가; 티켓 수령 시점 미상이면 `조건부 비교`로 표시.
- 상위 선택지 점수가 비슷하면 경합 안내. 성공 확률 또는 도축 자동판단 없음.
- `decision_ui_r6.py`: 사용자가 검수 상태를 입력하고 추천 근거를 조회하며 JSON으로 저장하는 ⑦ 탭.
- 기존 육성 DB의 `turns` 테이블에 `r6_review_json` 컬럼을 데이터 삭제 없이 추가. 유효한 R6 분석이면 턴 기록과 같이 저장.
- R6 결과는 목표·현재 턴 수치·입력 행동이 달라지면 재검수를 요구. 이전 턴 결과를 자동 전용하지 않음.
- 개발/패키지 버전 0.6.0 반영, Windows 수동 배포 스크립트 및 체크리스트 갱신.

## 기술적/기능적 제한

1. 수치 가중치는 실전 데이터로 보정·교차검증되지 않았습니다. 레이스나 외출의 실제 기대효과는 사용자가 직접 입력해야 합니다.
2. 향후 지원하고자 하는 인연도 전체 게이지/특별 이벤트/건설 계획/코스별 스킬 발동 등에 대한 최적화는 아직 없습니다.
3. 티켓 지급 시점과 경기장의 숨은 제약을 프로그램이 직접 읽어오지 않습니다.
4. `R6`은 **매 턴의 확인된 선택지끼리 계산한 상대 비교기**이지, 현재 게임의 정답이나 학습된 모델이 아닙니다.
5. 게임 조작/자동 육성/자동 도축 동작은 수행하지 않습니다.
6. 저장된 분석 결과에 `ml_training_label_verified=false`를 명시하여 가상 데이터를 정답처럼 사용하지 않도록 합니다.
