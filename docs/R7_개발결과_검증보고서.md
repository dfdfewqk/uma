# Uma Trainer KR V0.7 R7 — 개발 결과 및 검증

## 신규 기능

1. 기존 R6 앱에 `⑧ R7 무인도 시설 계획` 탭 추가. 기존 R1~R6 탭과 SQLite 데이터 저장 유지.
2. 시설 6종 레벨·분기 확인, 터커 브라인 등급별 건설 코스트, 시설 비용과 강화 가능 여부 검사.
3. 현재 단계부터 시니어 6월 최종 평가회까지 다단계 후보 건설 경로 3종 탐색. 가중치는 실험값이며 최적 보장 없음.
4. 캐릭터 목표 스탯과 사용자가 입력한 서포트 카드 종류·성장 보정(한 종류)을 우선순위 계산에 참고.
5. 사용자가 확인한 평가회 발전 Pt 목표·잔여 턴·턴당 예상 획득량으로 단순 부족량 계산. 빈 항목이 있으면 계산 보류.
6. 섬 티켓 상한의 시니어 9월 후반 구조 차이를 반영 (정확한 전환은 **시니어 9월 전반**); 다음 티켓 임박 시 손실 위험을 경고하되 자동 사용하지 않음.
7. 계획 결과 JSON을 원자적으로 저장하며 입력 변경 시 내보내기 차단. 새 세션/턴에 과거 검수 결과 자동 재사용 방지.

## 검증

- R1~R6 기존 자동 테스트 93개 유지.
- R7 신규 자동 테스트 23개 포함해 총 **116개 unittest 통과** (`python -m unittest discover -s tests -q`).
- Linux Xvfb 가상 디스플레이에서 실제 앱 실행 후, 9개 탭 확인, R7 화면 실행, 테스트 입력으로 3개 계획 후보 생성 및 화면 캡처 확인.
- Windows EXE 및 Setup.exe 실제 빌드/설치 미수행. GitHub Actions 배포는 수동 실행 설정만 유지.
- 한국 서버 실제 게임 스크린샷 OCR, 일본 실전 영상의 정확한 턴별 상태 전수 검수 및 ML 학습은 미수행.

## 주요 한계

건설 단계별 계획을 표시하지만 **실제 게임 수치에 기반한 최적화 모델은 아닙니다**. 발전 Pt/평가회 완주 확률이나 챔미·리오히 승률을 예측하지 않습니다. 초기 개발본이며 외부 공개 전 실PC 검증이 필요합니다.
