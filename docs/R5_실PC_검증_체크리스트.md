# 실제 Windows 한국 서버 점검 항목 (R5)

- [ ] Windows 10/11에서 수동 GitHub Actions 빌드 결과 EXE 단독 실행 확인
- [ ] Setup 설치/제거 후 `%LOCALAPPDATA%\UmaTrainerKR` 기존 데이터 유지 확인
- [ ] 1280×720 / 1920×1080 / DPI 125% 이상에서 전체 R5 화면 표시 및 세로 스크롤 확인
- [ ] 무인도 훈련 5종/섬 트레이닝 각 화면 PNG·캡처를 확보해 필드별 좌표 지정
- [ ] 실제 OCR 수치 5종 스탯 상승·스킬 Pt·실패율·티켓 정보의 정확도 측정
- [ ] OCR 오독(7→1 등)/부분 텍스트/다른 훈련 수치 혼합 시 추천 보류 확인
- [ ] 티켓 보유 0/1 상황의 섬 트레이닝 필수 여부 확인
- [ ] 턴 상태를 수정하거나 턴이 바뀐 후 이전 훈련 수치 재사용 차단 확인
- [ ] 실제 육성 3회 이상에서 훈련 추정값과 결과 비교. 정확한 게임 수식은 별도 검증
- [ ] 기존 V0.4 데이터베이스 기록의 보존 및 복원·백업 확인
- [ ] 설치 PC에 Python과 Tesseract가 없는 경우 앱은 실행되고 OCR만 사용할 수 없는지 확인
- [ ] 릴리스 전 실게임 약관 검토 및 오인식·추천 보류 UX 사용자 테스트

배포 판단: 위 항목이 확인되기 전에는 시제품 표시를 유지합니다.
