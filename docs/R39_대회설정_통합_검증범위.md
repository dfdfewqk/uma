## 최종 요구사항 — 단계적으로 구현하고 실제 검증할 항목

1. 사전 캐릭터·서포트 덱·계승 인자는 사람이 선택한다. 육성 도중 숫자 수동 입력이나 훈련 5종 강제 순회를 요구하지 않는다. 정보 부족 시에만 특정 화면을 클릭해서 확인하도록 안내한다.
2. 한 번에 1순위 행동과 이유 1~2줄 표시. 현재 훈련 서포트 위치·인연·우정, 스탯 목표 대비 부족량, 스킬 Pt·힌트, 시설·발전 Pt·섬 티켓, 다음 턴 특기율, 터커 외출, 목표/일반 레이스를 비교한다.
3. 일반 레이스는 고정 주기가 아닌 상황별 효율로 판단한다. 다음 턴 필수 레이스로 소멸하는 버프는 미래 이득으로 계산하지 않는다. 시설도 덱과 진행 상황에 맞춰 선택한다.
4. 서포트 이벤트는 카드 버전/진행 단계/선택/연속 종료/금색 스킬 분기를 검증해 추천한다. 게임 내 효과 보기에서 확인한 실제 결과를 저장한다. 조기 종료 선택지와 다른 금색 스킬 분기는 구별한다.
5. 최종 대회용 스킬은 육성 마지막에 구매한다. 육성 중 같은 목표 레이스에 연속 패배해 재도전하는 경우에만 실제 출전 거리·각질에 맞는 유효 스킬 1~2개 구매를 검토한다. 무관한 거리·각질 스킬 구매 금지.
6. 자동 모드는 나중에 별도 개발한다. 캐릭터·덱·목표·반복 횟수는 사람이 결정한다. 같은 설정으로 지정 횟수만 반복하며 고점·평범·도축·실패도 모두 회수에 포함한다. TP 부족 시 무료 회복 아이템 우선, 없으면 자연 회복 대기; 유료 재화 자동 사용 금지. 가능한 육성은 끝까지 진행한다.
7. 턴별 수치·선택·실제 결과를 구조화해 남기고, 확인된 임시 이미지부터 정리한다. OCR 오류·예외 화면은 보존한다. 사용자가 따로 보관한 파일은 삭제하지 않는다. 새로운 규칙은 검증 후 적용하며 시나리오/패치/출처/검수 상태/모델 버전을 분리한다.
