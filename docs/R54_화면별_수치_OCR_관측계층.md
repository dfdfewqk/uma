# R54 — 한국 서버 게임 수치 판독 계층 (4단계)

기준: R53 `e0e9b77fa88ca062899ff3336a2b0b2f230ad432`. R51 기준 백업 브랜치와 현재 사용자 설정 파일은 수정하지 않는다.

## 구현
1. R4 기반 필드 9개(스피드, 스태미나, 파워, 근성, 지능, 체력, 스킬 Pt, 섬 티켓, 발전 Pt)에 훈련 **실패율** 후보를 추가한다. 실패율·인연·우정 등을 임의 추정하지 않는다. 인연과 우정은 숫자 OCR이 아니라 그래픽 상태 판독 과제로 5단계에서 실제 화면으로 별도 검증한다.
2. 게임 화면 종류별 수치 영역을 사용자가 지정하는 R54 등록 대화상자를 추가한다. 레이스·시설·스킬·육성 종료 등 허용된 장면에서 숫자를 읽을 수 있지만, 장면별 위치를 임의 고정하지 않는다.
3. 등록한 원본 창 비율·크기가 달라진 경우 후보를 폐기. 사용자 ROI 파일 `%LOCALAPPDATA%\UmaTrainerKR\r54_numeric_regions.json`은 중복 덮어쓰기 금지/원자적 쓰기/링크 거부/용량 상한.
4. Tesseract OCR 신뢰도 80 미만과 범위 밖 숫자·모호한 문자열·비어 있는 필드는 폐기. 같은 장면/게임 창/배치·턴 조건에서 같은 숫자 2회 연속 관측해야 **OCR 잠정 후보**로만 표시.
5. R54 입력값을 자동 클릭, 스킬 구매, TP 충전, 학습 정답, R46 검수 완료 턴으로 승격하지 않는다.
6. 기존 R50 TP/스킬 자동 조작 수치 검증 모듈은 유지하며 R54 설정과 구별. 기존 R4 프로필은 같은 훈련 장면에 R54 영역이 없으면 그대로 사용한다.
7. 화면 전환/로딩/인식 실패 시 오래된 후보를 폐기. 화면이 다른 상태에서 스탯을 재사용하지 않는다.

## 아직 확보하지 못한 게임 화면
- 실제 한국 서버의 각 필드 위치/화면 배율별 OCR 결과, 인연 게이지 및 우정 배치, 훈련 실패율/선택지/스킬 Pt의 실제 OCR 성공률.
- 이 단계의 테스트는 합성 스크린샷과 모의 OCR. 게임 UI 실검증이 아니며 AI 고점 추천의 완성을 의미하지 않는다.

## 사용자용 (새 포터블 빌드 이후)
도우미의 '설정·개발자 점검 보기' → 'R54 숫자 OCR 영역 등록'에서 화면/필드를 고른 뒤 4초 캡처, 숫자 영역을 드래그하고 수동 확인을 체크해 저장한다. 등록된 수치는 화면이 두 번 안정적으로 인식될 때 별표(*)가 붙은 후보로만 표시한다.
