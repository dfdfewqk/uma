# Uma Trainer KR R34 — 무인도 조건별 육성 검토 (오프라인, 연구용)

## 구현 범위

R33의 일본 서버 2025-06-30 조정 후 공략을 **확정 규칙이 아니라 검토 조건**으로 사용한다. 기존 R6의 상대점수·추천순위·저장 스키마·R15/R16 학습기·자동 조작 기능은 수정하지 않는다.

상세 프로그램 \`UmaTrainerKR.exe\` 실행 → **연구·상세 설정 보기** → **R34 무인도 조건** 탭에서 사용할 수 있다. 첫 화면의 Companion과 별개이며, 현재 버전은 실시간 게임 화면 자동 입력을 지원하지 않는다.

## 어떤 입력을 받는가

- ① 목표/② 턴에서 기존 자료 가져오기: 시나리오·대회 목적·남은 턴·사용자 목표/현재 스탯, 티켓 보유량·수령 대기 턴·발전 Pt·시설 레벨.
- **직접 확인한 값만** R34 화면에 추가: 티켓 사용 단계(\`미확인 / 첫 1~2회 / 이후\`), 서포트 인연 단계, 우정 훈련 발생 시설 수(0~5), 남은 필수 목표 레이스 수, 다음 목표 레이스까지 턴, 남은 외출 계획, 캐릭터 성장률 5종, 시설 정보 사용자 확인 여부.
- 비어 있는 숫자는 미확인(\`None\`). 없는 자료에서 임의값을 만들지 않는다. \`0\`은 실제로 0인 경우에만 직접 입력한다.
- 성장률은 다섯 스탯 전체를 정확히 알 때만 입력한다. 개별 카드 인연 게이지/다음 버프 유지 시간/시설별 실제 효율은 **아직 수집 안 됨**.
- 현재 입력된 사용자 목표 스탯을 공식 능력치 상한·승률 목표로 간주하지 않는다.

## 무엇을 분석하는가

1. **첫 1~2회 티켓**: 초반 인연 확보용으로 조기 사용을 검토할 수 있으며, 우정 3곳 미만만으로 섬 훈련을 배제하지 않는다. [R33_H01]
2. **이후 티켓**: 서로 다른 우정 시설 수가 3 이상일 때 섬 훈련을 유망한 비교 후보로 표시한다. 3 미만이라도 수령 임박·만료 위험·목표 레이스를 함께 따진다. [R33_H02]
3. **시설·스탯**: 사용자 목표 대비 부족량, 성장률·확인한 시설 레벨·발전 Pt를 **분리 표시**한다. 이 값으로 시설 최적 업그레이드 순서를 추정하지 않는다. [R33_H03]
4. **필수 레이스/외출과 남은 턴**: \`남은 전체 턴 - 남은 필수 목표 레이스 수\`를 자유 턴 **상한**으로만 표시한다. 기타 강제 이벤트는 반영하지 않는다. 보유 티켓과 계획 외출의 행동 횟수가 상한을 넘으면 일정 충돌 경고. [R33_H06/R33_H09]
5. **챔미·리오히**: 높은 평가점만으로 실전 경쟁력을 주장하지 않는다. 확보·구매 가능한 필수 스킬 별도 확인. [R33_H07]

모든 항목은 **행동 선택 확정이 아니라 점검 질문/경고**다. 게임 서버·패치·훈련 수치가 검증되지 않았으므로 R6 점수나 추천행동에 자동 가중치를 적용하지 않는다.

## 데이터 호환성 및 테스트

- 기존 \`RunProfile\`, \`TurnState\`, \`storage\`, \`decision_r6\` 파일 **변경 없음**. R34 입력은 화면 내부에서만 관리되며 기존 DB에 기록·외부 전송되지 않는다.
- 점검 엔진: \`island_context_r34.py\`, 화면: \`island_context_ui_r34.py\`.
- 합성 데이터 회귀 테스트: \`tests/test_island_context_r34.py\`. 현재 턴 미확인, 최초/이후 티켓 구별, 티켓 없음, 남은 레이스/외출 충돌, 스탯·시설 정보 검증, 불가능한 값 차단, R6 비침투를 확인한다.
- 윈도우 검증 빌드는 **이번 커밋에서 자동 실행하지 않는다**. GitHub CI에서 소스·빌드 테스트가 통과하고 로컬 GUI를 확인해야 Windows 실행이 검증된다.
- 게임 화면이 없는 환경에서 연구 모듈을 검토한 것으로, 우마무스메 한국 서버 OCR·자막/영상 기반 턴 검증·모델 학습의 성공 증명은 아니다.

## 차기 단계

직접 검수한 게임 턴이 확보되면 실제 우정 시설·서포트 개별 인연 게이지·티켓 사용 전후 스탯 및 필수 레이스와의 충돌을 동일 출처 그룹으로 연결한다. 이후 기초 R6 실험 가중치보다 실전 유용성이 낫다는 검증이 나올 때에만 계산 알고리즘 변경을 제안한다.
