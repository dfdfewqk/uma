# R19 — 게임 위 선택 안내 + 게임 옆 육성 정보창

## 사용자 중심 UI
- **게임 화면 위:** 지금 누를 훈련 또는 스킬 이름 옆에 짧은 표시. 마우스 클릭을 가로채지 않는 오버레이. 훈련·스킬 두 화면 모드 분리.
- **게임 오른쪽(자리 부족 시 왼쪽):** 챔미/리오히, 코스·각질, 현재 입력된 스탯/목표 스탯, R11 필수 스킬 획득 상태, R6 수동 검수 행동 우선순위, R12 코스별 스킬 후보.
- **기존 19탭 연구 프로그램:** 내부 설정·데이터 검수용으로 그대로 보존.

## 이 빌드에서 실제 동작하는 것
1. R18 Windows 게임 창 감시 화면에서 창을 고르고 감시 시작
2. `게임 위 표시 + 옆 정보창`으로 세부 현황 표시창 열기
3. 훈련/스킬 모드를 수동 선택하고 게임 미리보기에서 실제 항목 위치 지정, 항목 이름 입력해 로컬 저장
4. `현재 게임 화면 종류를 직접 확인했음`을 체크한 경우 동일 창 크기의 동일 장면 모드에 등록된 좌표를 게임 위에 표시
5. R6의 **현재 턴 검수 결과** 또는 R12의 **같은 코스·대회·각질 분석 결과**가 없는 항목은 `추천 보류` 표시
6. 클릭 통과 오버레이는 Windows에서만 생성; 사용자 입력값은 별도의 PC 로컬 파일에 보존

## 아직 동작하지 않는 것
- 화면에서 자동으로 훈련 버튼/스킬 이름을 식별하는 OCR+장면 분류기
- R11 목표, R12 추천 스킬이 실제 게임 스킬 구매 목록에 존재하는지 자동 감지
- 실제 게임의 추천 위치를 자동 찾아 강조하는 기능 (현재는 **수동 위치 지정**) 
- 자동 육성이나 스킬 자동 클릭. R18의 기존 '버튼 1회 클릭 실험'은 별개이며 실전 검증되지 않음
- 실제 한국 클라이언트, Windows 오버레이 클릭 통과, DPI·여러 모니터 호환성 검증 (실PC 확인 필요)

## 자료·안전 원칙
- OCR 결과를 검수 완료로 가정하지 않는다. 목표 스탯과 필수 스킬은 사용자가 지정한 값임을 표시한다.
- 게임 창이 활성화되지 않았거나 감시 중단, 해상도 변경, 잘못된 화면 종류에서는 게임 위 표식을 숨긴다.
- 추천 표시 자체는 게임을 클릭하거나 상태를 바꾸지 않는다.
- 배포를 위한 Windows EXE 빌드와 게임 정책 확인은 별도 작업. 자동 GitHub 배포 없음.
- 향후 새 시나리오에도 공통 HUD 스키마를 쓰고 시나리오별 자동 화면 분류·판단 엔진만 교체한다.

## Windows에서 검증할 순서
1. 게임 창모드 실행 후 R19 앱 실행
2. 실시간 연동 탭에서 게임 창 검색, 게임 표시영역과 DPI 확인
3. 게임 위 표시가 클릭을 막지 않는지, 게임 창 이동 시 표시가 따라오는지 확인
4. 훈련 화면과 스킬 화면에서 각각 명칭/위치 보정
5. 다른 턴·대회·캐릭터로 전환하면 예전 추천이 남지 않는지 확인
6. R12 스킬 목록에는 실제 구매 가능 스킬만 검수해서 넣었는지 확인
