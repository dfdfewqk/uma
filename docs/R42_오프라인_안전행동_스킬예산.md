# R42 — 게임 미실행 안전 판단 계층 및 예산 검증

기준: main의 R41. 이번 단계는 Windows EXE/설치파일/릴리스/배포를 생성하지 않는다. 기존 데이터·UI·R40 상태 저장 파일은 삭제·초기화하지 않는다.

## 추가한 구현

### 1. `skill_budget_r42.py` — 레이스 재도전용 스킬 Pt 검증

- 현재 목표 레이스에서 2회 연속 패배했고 남은 재도전 횟수가 있는 경우에만 육성 중 임시 구매 후보를 평가한다.
- 실제 화면에서 확인된 현재 레이스·거리·스킬 페이지·사용 가능한 스킬 Pt가 모두 필요하다.
- 스킬이 **해당 거리/각질/마장에서 실제 발동 가능한 검수 조건**과 일치해야 한다.
- 이미 구매한 스킬, 미확인 가격, 실제 화면에 없는 후보, 중복 스킬, 미검증 스킬은 제외한다.
- 우선순위·구매 비용을 고려해 최대 2개까지만 선택하고 총 가격이 보유 스킬 Pt를 넘지 않는다. 실구매 자동 조작은 제공하지 않는다.
- 후보를 구매하라는 확정 명령이 아니라 `PurchasePlan(proposal_only=True)`만 돌려준다. 스킬 등급/우선순위 값은 외부에서 검수 후 공급되어야 한다. 최종 대회에 적합한 스킬 우선순위 자체는 실데이터 검증 전이다.

### 2. `intent_gate_r42.py` — 중복 행동 제안·화면 전환 보호

- 창/육성/턴 ID, 화면 유형, 프레임 순번, 검수 상태와 보이는 행동 목록을 함께 검사한다.
- 동일한 턴·장면·행동 목록이 **연속 두 프레임**에서 안정적으로 확인되어야 행동 후보를 발행할 수 있다.
- 가상 프레임, 비활성 게임 창, 사라진 버튼, 중복/역행한 프레임은 제안을 거부한다.
- 이미 행동 후보를 발행했다면 검수된 **다음 장면 또는 다음 턴**을 관찰하기 전까지 동일 행동을 다시 제안하지 않는다.
- 후속 장면 확인 전에는 결과 기록을 완료로 간주하지 않으며, 낡은 프레임으로 확인 처리하는 동작도 차단한다.
- `send_game_input()`은 여전히 예외를 내고 실제 게임 클릭은 수행하지 않는다.
- 화면 좌표/이미지 인식/실제 게임 키보드·마우스 입력과 연결되지 않은 순수 소스 계층이다.

### 3. R40 기존 턴 값의 검증 강화

`turn_policy_r40.py`에서 다음 턴 필수 레이스 여부와 화면 검증 상태는 실제 bool이어야 한다. 문자열 `yes`, 숫자 `0/1`, 잘못된 스탯 자료, 부울 실패율 등을 잘못 받아들이지 않도록 한다. OCR 오인식에 따른 행동 추천 오류를 예방하는 목적이다.

## 검사 및 검증 범위

- `tests/test_safety_r42.py`: 재도전 규칙, 예산, 발동 조건, 100개 결정적 무작위 예산 사례, 같은 장면 두 번 확인, 전환 전 재실행 차단, 합성 프레임/비활성 창 차단, 엄격한 검증 상태 검사 포함.
- R42 핵심 2개 모듈을 로컬 Python 3.13에서 **11개 독립 단위 테스트 통과**했다(부울·OCR 자료 검증 추가 테스트 3개는 GitHub 소스 회귀 테스트 실행 전). 이 결과는 Windows·KR 실게임 검증이 아니다.
- 전체 저장소 `python -m unittest discover -s tests -q` 및 실제 소스 전용 GitHub Actions CI는 **아직 실행/통과 확인 전**이다.
- GitHub Actions의 `Validate source only (no EXE / no deployment)` 워크플로는 기존 수동 실행 전용 상태를 유지한다. **이번 턴에도 EXE/배포하지 않는다.**

## 다음 연결 순서

1. 실제 한국 게임에서 얻은 화면 OCR/버튼 검수 값과 기존 Companion/R28 검수 결과를 R40의 턴 행동 비교·R42의 안전 상태에 전달한다.
2. 검증된 캐릭터별 필수 레이스 캘린더, 이벤트 결과, TP 회복 아이템·지원 카드 단계 인식 자료를 추가한다.
3. 추후 실제 게임 화면에서 클릭할 위치/활성 상태/원하는 동작이 정확히 맞는지 확인한 뒤에만 입력 어댑터를 별도 구현한다.
4. 전체 테스트·Windows 실행·실게임 검증을 구분해서 진행한다. 검증된 실데이터가 충분히 쌓이기 전까지 ML 학습 성공을 표시하지 않는다.
