# R29 — 실제 게임 화면 수집 및 진단팩

## 사용자 흐름
1. 한국 서버 PC 클라이언트를 실행하고, 게임 옆에 Uma Trainer KR 도우미를 놓습니다.
2. 도우미의 `R29 · 실게임 화면 자료 수집`에서 훈련/스킬/시설/이벤트 화면 종류를 선택합니다. 이 선택은 **사용자 수동 태그**이며 자동 판별 결과가 아닙니다.
3. `4초 뒤 게임 화면 저장`을 누른 뒤 게임 창으로 돌아갑니다. 게임 창이 활성화되어 있고 크기와 위치가 바뀌지 않았을 때만 저장합니다.
4. 각 화면마다 필요할 때 1회씩 저장합니다. 중복 화면은 거절하며 한 묶음에 최대 12장입니다.
5. 사용자가 명시적으로 `ZIP 내보내기`를 눌러야만 외부로 전달할 수 있는 파일이 생성됩니다. 공유하기 전에 게임 화면에 계정명·개인 정보가 있는지 확인하세요.

## 저장 방식 및 검증
- `%LOCALAPPDATA%/UmaTrainerKR/r29_local_captures/` 아래에 PNG 및 해시 검증용 JSON을 보관합니다.
- 이미지 원본은 사용자가 변경하면 SHA-256 검사가 실패합니다.
- 이미지 파일은 자동으로 업로드하지 않으며 네트워크 통신·게임 클릭·키보드 입력도 수행하지 않습니다.
- 상태가 불분명하거나 다른 창이 활성화되었거나 도우미가 게임 위를 가리면 캡처를 거부합니다.
- 이 파일은 게임 호환성 확인을 위한 **실제 UI 자료**이지, 최적 육성 공략이나 ML 정답 레이블은 아닙니다.

## 아직 미검증
Windows 설치파일 실제 실행, 한국 서버 클라이언트의 창 식별 정확도, 스킬창·훈련 수치 OCR 정확도, 오버레이 클릭 통과 동작은 실제 PC에서 확인해야 합니다.

`python -m unittest discover -s tests -q`로 기존 + R29 기능 테스트를 실행합니다.
