# R4 Windows PC 실전 점검 체크리스트

게임을 열 수 있을 때 아래 순서만 확인하면 된다. 실제 개인 정보가 나타난 화면을 외부로 공유하지 않아도 로컬 테스트는 가능하다.

1. **Windows 실행**: GitHub 수동 Actions에서 EXE/Setup.exe를 생성한 후, 테스트 PC에 Python 없이 설치·실행되는지 확인한다. 현재 ZIP은 실행 소스와 빌드 설정만 들어 있다.
2. **화면 선택**: `⑤ R4 화면 인식`에서 무인도 훈련 화면을 PNG 파일로 불러온다.
3. **영역 지정**: 이미지에서 스탯 5개, 체력, 스킬 Pt, 티켓, 발전 Pt의 정확한 숫자 부분을 드래그한다. 숫자에 이름/아이콘이 섞이지 않도록 한다. 항목별로 `ROI 저장`을 누른다.
4. **OCR 설치**: Windows에 Tesseract를 별도로 설치한 경우 `OCR 후보 읽기`를 누른다. 없는 경우에도 오른쪽 칸에 직접 숫자를 입력해 수동 검수 및 적용이 가능하다.
5. **수치 검증**: 인식된 숫자를 실제 화면과 비교하고, 맞는 항목에만 체크한 후 `확인한 항목 적용`을 누른다. 스탯 등의 수치가 `② 턴 분석`에 들어오는지 확인한다.
6. **저장**: 행동 상승량은 기존 방식대로 직접 입력한다. `현 턴 기록 저장` 후 다시 열었을 때 이전 기록이 보존되는지 확인한다.
7. **해상도 변경**: 창 크기와 게임 UI 배율이 달라졌을 때 ROI를 재지정해야 하는지 확인한다. 인식된 숫자 및 실패 사례만 기록한다.
8. **실제 게임 검증**: 한국 서버 UI에서 20~50장 정도의 서로 다른 이미지로 필드별 정확도를 측정하기 전에는 '한국 서버 OCR 검증 완료'라고 표시하지 않는다.

중요: 이미지는 수집/분석을 위한 것이고, 이 버전은 게임을 클릭하거나 자동으로 중단/재시작하지 않는다.
