# Uma Trainer KR R6 — 향후 Windows 실PC 검증

## 설치 및 기존 데이터
- [ ] Windows 10/11에서 EXE 빌드 및 Setup.exe 설치·실행
- [ ] Python이 없는 PC에서 실행되는지 확인
- [ ] 기존 V0.5 SQLite 파일을 백업한 뒤 V0.6에서 열어 오래된 육성 기록이 보존되는지 확인
- [ ] 자동 배포/백그라운드 자동 조작이 없는지 확인

## 한국 서버 무인도 검증
- [ ] 실제 PC 화면에서 스탯·체력·기본 훈련 5종 OCR 후보 정확도 기록
- [ ] 우정 훈련 시설 수, 스킬 Pt, 실패 확률, 인연도·발전 Pt 관련 수치가 읽히는지 별도 검토
- [ ] 섬 트레이닝 티켓 사용 가능 여부와 지급 시점, 평가회·건설 계획을 실제 게임과 대조
- [ ] 휴식·외출·레이스의 실제 선택 가능 조건과 선택 후 수치 검증
- [ ] 챔미와 리오히의 실제 육성 기록을 각각 1회 이상 수동 입력·분석
- [ ] 경기장·각질·코스·스킬 목표 등 실제 요구사항을 별도 샘플로 검증

## 안전한 추천 게이트
- [ ] 미확인 선택지가 있으면 전체 추천이 보류되는지 확인
- [ ] 섬 티켓이 없으면 섬 훈련이 후보에서 제거되는지 확인
- [ ] 숫자가 틀리면 검수 항목을 수정하고 이전 R6 분석이 재사용되지 않는지 확인
- [ ] 턴을 저장한 뒤 이전 턴의 관측/가능 상태가 초기화되는지 확인
- [ ] 동률 또는 티켓 시점 미상인 경우 주의 문구가 나오는지 확인
- [ ] R6 검수 JSON/DB에 게임 원본과 실제 선택의 구분이 보존되는지 확인

**공개 배포 전 필수:** 한국 서버 실제 게임 화면 검증 + Windows 실행 테스트 + 약관 확인 + 조정 전후 일본 공략 구분 + 실전 데이터 보정.
