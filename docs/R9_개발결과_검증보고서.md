# Uma Trainer KR R9 — 무인도 실측 데이터 감사 및 보수적 보정

## 적용 범위

- Windows PC 앱 기반, 한국 서버 전용 사용 목표. 현재 연구 자료는 JP 수정 후 자료가 우선임.
- 챔피언스 미팅 / 리그 오브 히어로즈 **실전 육성** 전용. 평가점 전용·인자작 배제.
- 기존 R1~R8 소스, SQLite 기록, OCR, 무인도 시설 계획 기능 유지.
- 자동 클릭, 실전 경기 승률 예측, ML 학습, 공식 게임 내 스탯 수식 **미구현**.

## 수정 후 자료만 사용

- 적용 전환 기준: 일본 2025-06-30 늦은 밤(공략 사이트 약 23:20 기록). 일부 공지는 같은 날 오전/오후에 게시됨.
- R9에는 일본 출처 날짜가 **2025-07-01 이후**인 검수 자료만 허용하여 조정 당일의 불명확한 자료를 보수적으로 제외함.
- 일본 서버와 한국 서버는 절대로 동일 표본 그룹으로 섞이지 않음.
- 한국 서버는 실측·패치 반영 확인이 별도로 필요하며 `KR_post_patch_confirmed`는 데이터 제공자가 별도로 확인해 넣어야 하는 주장임.
- 게임 공식 무인도 안내: https://umamusume.jp/contents/game/scenario/designyourisland/
- 2025-06-30 수정 보도: https://dengekionline.com/article/202507/46134
- 수정 이후 환경 설명: https://gamewith.jp/uma-musume/article/show/499493

## 추가 개발

1. `calibration_r9.py`: CSV 필수 열 검증, 누락/중복/가상/검수 미완료/패치 혼합 배제.
2. `calibration_ui_r9.py`: ⑩ R9 실측 보정 탭, 빈 CSV 양식, 검수 결과 조회, 유사상황 관측값 비교, 요약 JSON 저장.
3. 동일 그룹 조건: 서버·패치·시나리오·대회·시기·훈련 유형·캐릭터·서포트 편성·추가 상황 키·시설 레벨 및 분기·우정 인원 **모두 정확히 일치**.
4. 그룹마다 최소 **10개 검수 실측 표본 / 8개 독립 육성**을 충족하지 못하면 모든 수치 추정 보류.
5. 충분한 조건에서만 실제 관측 자료 중앙값과 10~90백분위 범위, 서로 다른 육성을 제외하는 leave-one-run-out 오차를 제공. **미래 턴 예측이나 통계적 신뢰구간 아님**.
6. 원본 프레임 SHA256 필수, 같은 원본 프레임·훈련 중복 배제. 보고서에는 원본 영상과 전체 육성 기록을 포함하지 않음.
7. 자료가 변경되면 이전 감사 보고서는 내보낼 수 없음.

## 실제 데이터·검증 상태

- `research/r9_calibration/verified_observations_blank.csv`는 **헤더만 있는 빈 자료**임.
- 2026-10-15 현재, 실제 프레임별 일본 영상 턴 검수 **0건** (기존 R2/R3/R8 현황과 동일).
- 모든 수치 계산 테스트는 격리된 임시 가상 입력이며, 실제 데이터팩에 합치지 않음.
- 한국 서버 실화면 및 Windows EXE 설치 검증 **0건**.
- R9 계산기 결과는 실험적 관측 범위일 뿐, 우수한 선택이라는 학습 정답이나 추천 정답이 아님.

## 다음에 필요한 실증 작업

1. 2025-07-01 이후의 챔미/리오히 목적 일본 영상에서 원본 프레임·실측 옵션·실제 턴 상태를 검수하고 URL/해시/육성 ID 연결.
2. 한국 서버에 수정 후 시설 효과가 정확히 반영되는지 화면·증가량으로 대조.
3. 같은 조건으로 비교 가능한 표본이 일정량 확보되는지 통계적 커버리지 분석.
4. 수치 보정 결과를 기존 R6 점수에 통합하기 전, 사람 전문가 판단 및 미사용 육성 데이터로 검증.
5. Windows EXE/Setup.exe 실행 및 OCR 검증 뒤 배포 여부 별도 판단.
