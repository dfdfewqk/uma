# Uma Trainer KR — 2단계 한국 서버 실화면 수집 준비 (R51 기반 소스 수정)

## 기준과 실제 범위
- 작업 기준 HEAD: `26ec16f5da77082b22ea58ddcb01e3d503cc361e` (R51/v0.32.2).
- R29 화면 저장 경로만 보완하고 R48~R51 자동 조작·스킬·TP·학습·사용자 기록은 변경하지 않는다.
- R47.1부터 인식되던 작은 세로형 한국 게임 창(예: 384×700)을 R29 수집에서도 허용한다.
- 기존 5개 라벨은 유지하고 육성 준비/TP/훈련 미리보기 및 결과/휴식/레이스/시설/스킬/결과/반복/팝업 분류를 추가한다.
- 한 수집 묶음의 최대 화면 수를 12에서 40으로 확대한다. 중복 이미지, 위조 경로, 수정된 이미지, 출처/장면 오인 방지 조건은 유지한다.
- 사용자 선택 라벨은 `detected_scene=null`, `review_state=unverified`이며 모델 학습/자동 클릭 근거로 사용하지 않는다.

## 사용자 실게임 수집 순서
1. Windows 게임 실행 후 도우미를 게임 창 옆에 놓는다. 도우미의 '설정·개발자 점검 보기'를 열고 '2단계 · 실제 화면 자료 수집'을 연다.
2. 먼저 '훈련 미리보기' 라벨로 5종을 각각 표시하고 캡처한다. 실패율, 우정 훈련과 서포트 인연이 보이는 상세 화면도 확보한다.
3. TP 부족/무료 아이템/사용 후, 스킬 목록/구매 전후, 레이스, 이벤트 선택 전후, 외출, 무인도 시설/섬, 결과 및 재시작을 각각 사용자가 선택해 저장한다.
4. 저장 버튼을 누른 후 게임을 4초 내에 활성화한다. 창 크기가 바뀌거나 도우미가 가리면 수집하지 않는다.
5. ZIP 내보내기 전에 개인정보가 보이는 이미지가 없는지 직접 확인하고 필요한 자료만 제공한다.

## 저장과 검증 구분
- 사용자 PC 저장: `%LOCALAPPDATA%\UmaTrainerKR\r29_local_captures\`.
- 캡처·변경 감지: SHA-256, 원본 이미지·JSON manifest; 업로드 및 자동 게임 입력 없음.
- 기존 R50 등록과는 별도의 증거 자료 수집 기능이다. R50 버튼 프로필로 자동 승격하지 않는다.
- 신규 소스 회귀 테스트: `tests/test_capture_pack_r29.py`에 세로형 정상/비게임 거절/짧은 창 거절/미검수 태그 테스트 추가.
- **GitHub 소스 변경은 실제 한국 서버 OCR/Windows GUI 검증이 아니다.** 빌드/배포를 사용자 요청 없이 반복 수행하지 않는다.
- R29의 역사 문서는 원상 유지. 이번 보완 내역은 이 문서가 우선한다.
