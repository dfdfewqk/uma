# R28 — 사용자가 검수한 훈련 선택을 게임 화면에 표시

## 범위

- R22의 사용자 검수 완료 선택지로 생성한 1회성 추천 자료를 Companion으로 전달합니다.
- **실제 Windows 게임 창에서 캡처된** 현재 턴 훈련 5종(+ 섬 티켓 존재 시 섬 훈련)만 사용합니다.
- 기존 R6 점수는 연구용 임시 가중치입니다. 게임 공인 공식이나 학습 완료 모델이 아닙니다.
- R20 장면 분류, R21 버튼 이미지 위치 검출이 안정된 상태에서만 읽기 전용 표식을 표시합니다.
- 정상적인 게임 화면 전환을 감지하면 그 추천 ID는 폐기하고 이전 ID를 다시 활성화하지 않습니다.
- 유효시간은 120초이며, 턴 전환 시 사용자가 취소해야 합니다. **프레임 간에 전체 턴 전환을 놓치면 구별할 수 없으므로 자동 검증 완료라고 주장하지 않습니다.**

## 핵심 모듈

| 모듈 | 역할 |
|---|---|
| `recommendation_bridge_r28.py` | 현재 턴 사용자 검수 결과의 로컬 전달·만료·출처·오류 검증·이전 추천 차단 |
| `game_overlay_r28.py` | Windows 투명 클릭 통과 읽기 전용 원형 강조 표식 |
| `live_training_r22.py` | 선택지별 실제 창 캡처와 이미지 파일 입력 출처 구분 |
| `live_test_ui_r22.py` | 사용자가 명시적으로 현재 턴 추천 전달/취소 |
| `companion.py` | 게임 창/장면/버튼 재검증 후에만 추천·표식 출력 |

## 반드시 실PC에서 검증할 사항

1. 올바른 한국 게임 HWND 식별 및 게임 화면 캡처가 다른 앱 이미지와 혼동되지 않는지
2. 다섯 훈련 버튼 캡처/체력 변화 입력 시 누락·오인식 검수 흐름
3. 클릭 통과 Win32 EXSTYLE이 정상 적용되고 게임 클릭·포커스를 가로채지 않는지
4. 다른 창·턴·해상도·스킬 화면으로 전환할 때 표식이 즉시 사라지는지
5. 프레임 간 오버레이가 캡처에 섞이지 않는지, 스크롤/배율 변경에 틀린 위치를 가리키지 않는지
6. 2분 만료·시스템 시각 변화·구버전 입력 데이터와의 호환성
7. 설치 EXE와 Windows 사용자 프로필 데이터 분리, 제거 후 육성 기록 보존

## 제외

- 자동 클릭·자동 육성, 스킬 구매 버튼 검증 없는 표시, 영상 대사 자동 ML 학습
- 계정 접근, 데이터 수집 서버 전송, 제3자 플랫폼 접근/수정
