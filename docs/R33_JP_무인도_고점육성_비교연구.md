## 결과 범위

- 조건별 육성 가설 9개, 해소되지 않은 차이 3개.
- 직접 검수한 완주 영상/화면 0개, 직접 관측한 턴 0개, ML 정답 라벨 0개, 실제 학습 모델 0개.
- 기존 게임 점수와 R31.1 Windows 실행파일은 변경하지 않았다.
- 영상 길이가 몇 시간인지 정확히 검증된 무편집 고점 육성 VOD는 아직 확보하지 못했다. **라이브 방송 게시물 발견은 해당 영상 전체 시청을 뜻하지 않는다.**

## 서로 다른 공략의 차이

1. **시설 Lv5 고정 금지.** セリル이 올린 7월 4일 설명은 스피드·근성 5 레벨 최종 예시를 보여준다. 그러나 バーベ 작성자는 많은 마야노 육성에서 스피드 5로는 수치가 낭비돼 스피드 3~4, 파워·근성 5로 바꾸었다고 한다. 이는 동일 조건의 대조시험이 아니다.
2. **초기 티켓 vs 후반 티켓.** 초기 1~2장은 인연 구축 목적으로 사용 가능하지만, 인연 확보 후에는 3시설 우정을 노리는 설명이 중복된다. 만료 가능성을 지운 채 보편 규칙으로 코딩하면 안 된다.
3. **평가점 US vs 챔미/리오히.** 고점 해설에서 권하는 스탯·스킬 Pt 최대화를 대인전 승률 라벨로 쓰지 않는다. Merci의 7월 챔미 기록은 남은 스킬 Pt와 실제 구매 가능한 스킬이 다를 수 있다는 별도의 경고다.
