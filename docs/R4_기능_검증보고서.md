# Uma Trainer KR R4 — 스크린샷 숫자 인식 및 수동 검수

## 목표 및 실제 구현
- R3 모든 소스와 연구자료, 세션·턴 저장 구조를 유지했다.
- 시나리오 선택 구조는 유지하고 무인도 `island_post_patch_v1` 화면을 첫 대상으로 설계했다.
- PNG/JPEG/WebP 스크린샷 불러오기와 로컬 전체 화면 캡처 버튼을 제공한다. 전체 화면 캡처는 사용자 클릭 및 확인 후에만 진행한다.
- 표시된 이미지에서 항목별 숫자 영역(ROI)을 마우스로 지정하고, 비율 기준 좌표를 프로필 JSON으로 저장/불러오기한다.
- 대상 9항목: 스피드, 스태미나, 파워, 근성, 지능, 체력, 스킬 Pt, 섬 티켓, 발전 Pt.
- Tesseract(PC에 별도 설치 시)를 로컬 subprocess로 호출해 OCR 후보를 추출한다. 네트워크 전송을 수행하지 않는다.
- 유효범위 외 숫자·문자 혼동·낮은 확신도 결과는 확인 필요로 분리하고, 수동 수정과 체크 후 동의한 항목만 기존 턴 입력값에 반영한다.
- 적용 시 원본 파일 SHA256, ROI, 원시 OCR 후보, 최종 사람이 확인한 수치를 JSON 증거파일로 따로 저장한다.
- R3의 추천 엔진, 저장 DB, 수동 훈련 상승량 입력 기능은 그대로 유지한다.

## 검증
- R3까지 42개 + R4 9개 = **51개 단위 테스트 통과**.
- Linux Tesseract 5.5.0으로 **게임이 아닌 합성 테스트 이미지의 9개 숫자를 정확히 판독**했다.
- Xvfb에서 GUI 화면 로드/합성 이미지/9개 후보 표시까지 연동 테스트 완료.
- Windows용 GitHub Actions 수동 빌드에는 Pillow 의존성 및 R4 예제 파일 추가.
- 실제 한국 게임 화면 인식 정확도: **미검증**. 시나리오 전용 게임 화면 레이아웃 ROI: **사용자가 직접 보정 필요**.
- Windows Setup.exe 빌드 및 실행: **미검증**.
- 실제 우마무스메 영상의 검수된 개별 턴: **0건**.
- ML 학습, 최적 행동 공식 재현, 자동 조작: **없음**.

## 남은 작업
1. 한국 PC 클라이언트에서 무인도 훈련/시설 화면을 다른 UI 배율마다 확보해 ROI 보정.
2. OCR 테스트 — 전 화면이 아니라 사용자가 지정한 숫자 영역에 대해 필드별 인식률·오인식 사례 수집.
3. 훈련 선택지별 예상 성장량·우정 인원·실패 확률 읽기 기능은 다음 버전으로 분리한다.
4. Windows 설치형 실제 실행 확인; Tesseract 설치 없이 OCR을 제공할지 별도 배포 방식을 검토한다.
5. 데이터가 누적되면 사람의 검수결과/게임 결과를 연결해 오류율을 수치화. 자동 클릭/도축 미구현.

## 안전/프라이버시
- 화면 캡처 파일은 PC의 로컬 폴더에 저장된다. 타 앱/계정 정보가 함께 찍힐 수 있으므로 주의.
- 원본 이미지의 해시와 경로는 다른 서버로 전송하지 않는다.
- 합성 예제는 실제 게임 자료/ML 데이터로 사용하지 않는다.
- 사용자가 확인하지 않은 OCR 후보를 추천 입력값으로 사용하지 않는다.
- R4는 OCR 후보 수집 도구이지 자동 육성 또는 스킬 선택 자동화 프로그램이 아니다.
