# Windows + 한국 우마무스메 실PC 검증 체크리스트 (R7)

현재는 검증되지 않았으며, 테스트 준비 시 확인합니다.

- [ ] Windows 10/11에서 `UmaTrainerKR_Setup_0.7.0.exe`로 설치·기동 확인
- [ ] 새 설치/기존 사용자 데이터베이스 보존 및 기존 R6 육성 기록 확인
- [ ] 한국 서버 무인도 화면의 시설 이름, 시설 비용, Lv3 본능/기교 분기 비용 확인
- [ ] 터커 브라인 3돌 이상 / 0~2돌 / 미편성 상황에서 건설 계획 코스트 비교
- [ ] 각 평가회별 발전 Pt 게이지와 실제 필요한 획득 수치 확인
- [ ] 실제 한 건설 기간에서 동일 시설 연속 2레벨 강화가 가능한지 확인 (R7은 보수적으로 불가 가정)
- [ ] 시니어 9월 전반 섬 티켓 2장 지급과 보유 상한 3장 전환 확인
- [ ] R7 추천 상위 3개 경로와 실제 수치의 차이를 턴마다 기록
- [ ] 한국 서버의 정확한 화면 좌표와 OCR 반응 보정
- [ ] 실패·도축·완주 육성 사례 데이터 확보 후 휴리스틱 성능 평가
- [ ] 게임 약관 및 계정 정책 검토 (자동 조작은 여전히 미포함)

**기존 정상 기능 보존, 모든 개발 파일 일괄 테스트 이후 최소 배포**를 원칙으로 합니다.
