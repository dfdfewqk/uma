# R41 — 게임 없이 진행한 자동 육성 엔진 보강 및 가상 턴 재생

작업 대상: dfdfewqk/uma. 기존 Windows 프로그램·R40 커밋을 유지하며 **실게임 실행, EXE/설치파일 생성, 배포를 하지 않음**.

## 이번 소스 보완

### 1. R40 자동 육성 안정성 개선

auto_core_r40.py에서 TP가 부족할 때 무료 회복 아이템의 수량/효과가 미확인이라면 무조건 자연 회복으로 분류하던 문제를 수정했다. 미확인은 검증 대기로 보낸다. 알려진 TP 상한과 현재 TP가 모순이면 거부한다. 게임 조작 가능한지 여부는 여전히 별도 검증이 필요하며 현재 actuate_game은 RuntimeError로 차단한다.

육성 진행 상태에 완료된 회차만큼 결과 기록이 존재하는지, 완료되지 않은 단계에 진행 중 ID가 잘못 남아 있지 않은지, 반복 횟수 카운트가 일치하는지도 추가 검사한다. 고점·평범·도축·실패한 각 육성은 모두 총 지정 횟수에 포함하며 레이스 재도전은 별도 카운트하지 않는다.

### 2. 일본 참고 자료를 원본 그대로 활용

R13 기존 2025년 일본 무인도 공략에는 4개 대회(1회차 챔미, 2회차 리오히, 3회차 챔미, 4회차 챔미) 각각 도주/선행/선입/추입 **총 16개 프로필**, 공략상 서포트 후보 **34개**가 남아 있다.

reference_profile_r41.py로 기존 공략 문서에서 각 회차·각질의 후보 스킬, 제외 검토 스킬, 원본 출처 ID를 읽는다. 첫 한국 서버 대회 코스(한신 2200m)는 기존 2차 출처를 연결하고 한국 공식 공지 최종 대조는 미완료다. 2~4회차 한국 서버 코스는 미확정이다. 공략 프로필은 JP 참고용이며 자동 스킬 구매에 사용할 수 없다. KR 패치·게임 실제 보유 여부·발동 조건 확인 필요.

### 3. 게임 미실행 4턴 연속 재생

offline_replay_r41.py, research/r41_synthetic_replay.json: 다음 네 상황을 순차 재생한다.
- 주니어 시기 약한 훈련보다 스킬 Pt를 주는 일반 레이스의 비교 가치
- 목표 스탯이 거의 찬 상태에서 스킬 Pt 비중 증가
- 다음 턴 필수 레이스가 있어서 1턴 지속 특기율 보너스가 훈련에 쓰이지 못하는 상황
- 높은 훈련 실패율과 휴식 비교

동일 목표/덱/계승에 대한 고점·도축·실패 **3회 결과 합성 기록**까지 모사한다. 가상 순위와 실게임 권고를 분리한다: 합성 화면에서 real_game_action은 항상 null, trained_model은 false, real_training_samples는 0이다. 임시 휴리스틱 점수는 실제 승률이나 고점 최적성을 의미하지 않는다.

게임 없이 실행하는 예:
python offline_replay_r41.py research/r41_synthetic_replay.json

### 4. 용량을 위한 이미지 정리 안전장치

capture_retention_r41.py는 프로그램이 직접 소유한 r41_temp_captures 전용 폴더만 관리한다. 이미지를 정리하려면 그 이미지가 앱 목록에 등록돼 있고, 결과 분석이 검수됐고, 텍스트 기록도 있고, 원래 파일과 SHA-256가 같아야 한다. 예외/미확인 이미지는 보존. 기본 dry_run=True에서는 대상 확인만, 실제 삭제는 별도 명시적으로 요청한 경우에만 한다. 사용자 사진, 다른 게임 캡처, 기존 R29 자료는 건드리지 않는다. 현재 새 이미지 자동 수집·자동 삭제 연결은 미구현이다.

### 5. 회귀 테스트·검증 범위

신규 파일:
- tests/test_offline_replay_r41.py
- tests/test_reference_profile_r41.py
- tests/test_capture_retention_r41.py

기존의 source-only-r40.yml 수동 워크플로에 R41 가상 재생 단계를 추가했다. 이 워크플로는 Python 컴파일·전체 unittest·가상 재생만 하고 Windows 빌드·배포/Release를 만들지 않는다. 자동 실행 트리거는 없다.

실행 명령:
python -m compileall -q .
python -m unittest discover -s tests -v
python offline_replay_r41.py research/r41_synthetic_replay.json

**이 작업에서는 GitHub Actions를 실행하지 않았으므로 전체 테스트 성공을 주장하지 않는다.** 소스·데이터 구조와 GitHub HEAD만 확인한 상태다.

### 앞으로 실게임이 필요하게 되는 작업

Companion에서 실제 한국 서버의 현재 서포트 카드 배치/인연/우정, 스탯 상승량·스킬 Pt, 시설·티켓, 이벤트 보상 표시·연속 종료 분기, 필수 레이스 달력, 아이템과 TP 상태, 육성 완료 화면까지 안정적으로 수집·검수해야 한다. 검증을 거쳐 R40 모듈을 실시간 관측 파이프라인에 연결한 후, 안전한 게임 입력 및 복구 정책을 별도 구현한다. 검증한 턴별 실제 효과를 모으기 전에는 ML 학습 완료로 표기하지 않는다.
