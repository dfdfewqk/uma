# R30 — 무설치 포터블 업데이트

## 기본 방식

1. GitHub Actions에서 Windows **수동 빌드**를 실행한다. 기본 `publish_release=false`는 빌드 결과만 Artifacts에 남긴다.
2. 확인된 프로그램의 ZIP 이름은 `UmaTrainerKR-Portable-v0.30.0.zip`, 해시 파일은 `.zip.sha256`로 생성된다.
3. 첫 사용자는 ZIP 압축을 풀어 `UmaTrainerKR_Companion.exe`를 실행한다. 설치 프로그램은 필요하지 않다.
4. 프로그램 하단 **R30 · 무설치 업데이트**에서 GitHub에 공개된 새 릴리스를 확인한다. Windows 포터블 EXE에서 실행 시 시작 직후 자동 확인, 실행이 유지되면 하루마다 확인한다.
5. 업데이트가 있으면 사용자가 **새 포터블 버전 받기 및 실행**을 직접 선택한다. SHA-256, ZIP 구성, 버전을 검증한 후 기존 폴더와 나란히 새로운 폴더를 생성한다.
6. 사용자가 확인하면 새 `UmaTrainerKR_Companion.exe`를 실행하고 기존 도우미 창은 종료된다. 이전 버전 폴더는 삭제하지 않는다.

## 안전장치

- 출처: `dfdfewqk/uma`의 GitHub **공개된 최신 안정 릴리스**만 허용. 드래프트와 프리릴리스, 오래된 버전은 설치하지 않는다.
- SHA-256 해시와 ZIP 내부 버전·실행파일 목록 검사. 오류, 비정상 다운로드, 압축 경로 침범 시 **업데이트 중단**, 기존 버전 유지.
- 이전 EXE를 덮어쓰지 않으며, 기록·화면 보정 설정은 `%LOCALAPPDATA%\UmaTrainerKR`에 계속 저장된다.
- 다운로드는 명시적인 클릭 이후에만 시작한다. 게임 자동 클릭과는 관련이 없다.
- GitHub Releases에 새 버전이 **실제로 발행되지 않았다면** 업데이트는 나오지 않는다. GitHub 소스 커밋만으로는 설치된 프로그램이 바뀌지 않는다.

## 약 4개월 단위 업데이트에 대한 운영 규칙

- 육성 시나리오·한국 서버 밸런스 변경, 훈련 인식 문제, 설치·보안 수정은 수시로 확인한다.
- **최대 약 4개월을 목표로** 버전 검토와 테스트 및 릴리스 배포를 운영하되, 코드만으로 자동 개발·배포를 보장할 수는 없다.
- 새 버전 출시 시 **전체 소스 테스트 → Windows 러너 EXE/설치/포터블 검사 → 게임 화면 테스트**의 결과를 구분해 공개한다.
- 사용자 확인 후 Actions의 `publish_release=true`를 선택한 실행에서만 GitHub Release를 발행할 수 있다. 이 옵션은 기본으로 `false`다.
- 캐릭터·서포트·시설·코스 규칙의 업데이트 여부는 앱 자체 업데이트와 별개로 정확한 **한국 서버 패치 버전**을 확인해야 한다.

## 아직 검증이 필요한 부분

- Linux 개발 환경에서 소스 및 모의 ZIP 테스트는 진행했지만, 실제 Windows에서 포터블 ZIP 다운로드→실행→교체 전 과정은 아직 시험하지 못했다.
- Tesseract OCR 설치는 기본 포터블 ZIP에 포함되지 않았으며 별도 준비가 필요할 수 있다.
- 무인도 판단·오버레이 및 자동 육성은 실게임 검증 완료 상태가 아니다. 자동 클릭은 미지원.
