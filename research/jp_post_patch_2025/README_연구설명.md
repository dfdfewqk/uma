# Uma Trainer KR — 일본 무인도 시나리오 수정 후 연구자료 R1

기준일: 2026-10-15 | **일본 서버 2025-06-30 변경 이후 자료 중심**

## 자료 규모와 현재 한계

- 검증한 공개 출처 25개 (영상 6개 포함)
- 출처가 연결된 관찰/전략 주장 28개
- 실전 기록·후기·영상 소개에서 식별한 사례 9개
- 영상 설명란에 공개된 챕터 지점 12개
- **실제 게임 화면에서 직접 판독한 개별 턴: 0개**
- **ML 학습용 정답 라벨 0개** (실제 게임 영상을 전부 봤다거나 학습했다고 주장하지 않음)

## 파일

- `sources.csv`: 원문 출처, 공개 일자, 사용 범위, 검토 깊이
- `evidence.csv`: 출처 기반 관찰과 제품에 줄 영향; 공략 주장은 게임 내부 규칙이 아님
- `player_cases.csv`: 문서/영상 메타에서 확인되는 육성 및 경기 사례 (도축, 완주 후 폐기, 실전 패배 구별)
- `hypotheses.csv`: 실제 추천·도축 알고리즘에 넣기 전 검증할 가설
- `video_chapters.csv`: 영상 설명에 나온 검수 위치 (실제 그 장면을 본 건 아님)
- `turn_annotations.csv`: **아직 비어 있음**. 원본 화면을 직접 검증한 뒤 기록할 실제 턴 데이터 표준 형식
- `manifest.json`: 연구자료 범위와 검증 상태
- `validate_research.py`: 외부 패키지 없이 CSV 교차 검증하는 스크립트

## 사용법

1. 엑셀 파일 또는 CSV로 출처와 개별 케이스를 검토한다.
2. 공략에서 발견한 선택 기준은 `hypotheses`에 먼저 넣는다. 곧바로 엔진의 가중치를 고치지 않는다.
3. 원본 영상의 실제 화면에서 턴, 상태, 후보 행동, 실제 선택 및 결과를 확인한 뒤에만 `turn_annotations`에 추가한다.
4. **자동 도축은 활성화하지 않는다.** 도축 사례는 플레이어 의사결정이며 최적 행동의 검증이 아니다.
5. 향후 한국 서버 수치를 확보하면 별도의 `server=KR` 검증을 거쳐야 한다.

## 품질 주의

- 2025-06-30 밸런스 변경의 **공지** 시각과 **적용** 시각은 출처 사이 표기가 달라 확정하지 않았다.
- S017의 2025-09 챔미 회고는 제목과 본문의 경기장 표기가 일치하지 않는다. 케이스의 코스는 `course_inconsistent`로 유지한다.
- C006은 **완주 후 출전 제외**이지 육성 중도 포기가 아니다. C009는 실제 중도 재시작에 관한 익명 경험담이다.
- S022는 팀 경기장(チーム競技場) 공략이므로 도축 기준의 참고 후보로만 활용하고 챔미·리오히 라벨로 사용하지 않는다.
- R1 연구팩은 기존 V0.2 판단 엔진과 파일 저장 기능을 **변경하지 않는다**. 잘못된 확신으로 실제 추천 점수를 바꾸지 않기 위해서다.
